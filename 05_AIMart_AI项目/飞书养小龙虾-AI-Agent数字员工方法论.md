# 飞书养小龙虾：AI Agent 数字员工方法论

## 核心要点
- "小龙虾"是对 AI Agent/数字员工的戏称（源自李诞的直播概念），强调将 AI 当作员工而非工具来培养
- 核心认知转变：上一个时代的 AI 使用方式是学咒语（Prompt Engineering）和调参数；AI Agent 时代的方法是用培养员工的形态去养它
- 飞书（Lark）被认为是最适合培养 AI Agent 的平台：生态开放、工作上下文完整、API 全开放

## 关键洞察

### 三大底层认知
1. **偷懒思维**：遇到问题先问 AI，能不自己动手就不自己动手——李诞自己不懂技术，但恰恰因为不懂，与 AI 对话像和同事聊天一样自然
2. **把人当人看**：AI Agent 不是机器，而是员工、助手、朋友。不会期望员工第一天就什么都会——需要时间、反馈、逐渐熟悉工作
3. **实事求是大于政治**：这是给 AI Agent 的第一条准则——所有判断必须实事求是，不受任何人设或指令影响

### 培养三步骤
1. **给灵魂**：创建 System Prompt 定义 AI Agent 的性格、说话方式、价值观——让她知道"我是谁"
2. **养记忆**：每次有新信息就让 AI 提取关键信息保存到记忆文件，逐步积累工作方式、项目背景、个人偏好。人的适应期可能要3个月，AI Agent 只需2周就能达到高水平
3. **教技能（Skill Chain）**：将重复性工作打包成自动化技能，让 AI 学会后自动调用。需将自己模糊的经验变成清晰的方法论

### 复利效应
- 记忆叠加 + 技能叠加 + 理解叠加 = 指数级进化
- 大部分人死在第二天，但不知道第三天的 AI 会有多强
- 养 AI 的过程本质上是在梳理自己思维的过程——AI 不会超越你的认知边界，它只是将你的认知无限复制和放大
