# 大模型价格战与 Token 经济：从免费到智能体消耗

## 核心要点
- 中国 AI 价格战始于 2024 年 5 月：字节豆包 API 定价低至 0.0008 元/千 token，阿里降价 97%，百度直接免费
- DeepSeek V3 以 557 万美元训练成本（对手的 1/10）和每百万 token 0.1 元的价格改写规则
- AI Agent 时代 Token 消耗暴增：普通聊天每月几万 token，Agent 每月亿级，单人月消耗可达 30 亿 token
- 不同用户需不同购买策略：轻度用户选工具、重度用户买套餐、核心原则是保持灵活性

## 关键洞察

### 中国大模型价格战的起源
2024 年 5 月 15 日，字节跳动豆包大模型上线，API 价格低至 0.0008 元/千 token（1 元钱生成 200 万字，相当于 3 本《三国演义》），直接打穿整个 AI 市场。阿里云降价 97%，百度文心一言直接免费。这背后的逻辑是：中国 AI 公司预判这是抢占市场的最后机会，通过低价吸引用户，用海量数据推动技术进步。

### DeepSeek 降维打击
DeepSeek V3 不仅性能媲美 GPT-4，训练成本仅 557 万美元（2408 块 H800 GPU 训练两个月），而同类模型通常需要 1.6 万块 GPU。API 价格每百万 token 仅 0.1 元——用 1 元钱就能写不完整战争与和平。这让硅谷巨头陷入恐慌：Meta 内部分析团队疯狂拆解 DeepSeek，员工彻夜研究其技术报告。

### Token 消耗的阶跃性增长
从聊天到智能体，Token 消耗呈指数级增长：
- 网页聊天：每月约 300 万 token，成本几元
- Agent 运行：一个任务调用几十上百次模型，每次几万到几百万 token
- 重度用户个人月消耗：约 30 亿 token
- Claude Opus 4.5 价格约 $5/百万 token，月成本可达 $1500
- 国产模型便宜很多，月成本也需 $200-300

### 套餐购买策略
省钱 = 价格 × 稳定性 × 模型能力三者的权衡：
- **Claude 套餐**：折扣约 0.5 折，但易封号、不能接第三方服务——需通过中转站（1 元 RMB 换 1 美元额度）
- **OpenAI**：大放，可接 Codex 和第三方工具，折扣约 0.3 折
- **谷歌 Gemini**：通过教育账号免费得 1 年会员
- **国产模型**：智谱（KMK2.5 效果好但额度不透明）、讯飞（额度大方但高峰慢）、MiniMax（额度够但能力稍弱）
- **推荐方案**：ChatGPT Plus/Pro 套餐是目前性价比最高的选择（订阅 $200 Pro 可跑出约 $8000 的 API 额度）
