# Environment Setup

## Toolchain

- Runtime: Node.js 20+
- Package manager: pnpm
- Language: TypeScript
- Frameworks: Next.js, TypeScript, Zod, Vitest, pnpm
- Test runner: Vitest

## Required Commands

- pnpm install
- pnpm lint
- pnpm test
- pnpm build

No global package install, system package install, or production resource setup is required for v0.1.
