# Install Plan

Project: Todo API MVP

## Required Toolchain

- Runtime: Node.js 20+
- Package manager: pnpm
- Language: TypeScript
- Frameworks: Next.js, TypeScript, Zod, Vitest, pnpm
- Test runner: Vitest

## Commands

Run these from the project root:

```bash
pnpm install
pnpm lint
pnpm test
pnpm build
```

Do not install system dependencies or global packages without approval.
