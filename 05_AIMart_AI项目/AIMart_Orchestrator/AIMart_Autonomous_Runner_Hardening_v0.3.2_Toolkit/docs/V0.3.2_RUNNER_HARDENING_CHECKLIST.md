# V0.3.2 Runner Hardening Checklist

## Objective

Harden the autonomous runner so future tasks do not require repeated V1/V2/V3 hotfix scripts or manual diagnosis.

## Must pass

- [ ] v0.3.1 remains frozen and historical releases untouched.
- [ ] Runner stage machine exists.
- [ ] Failure classifier exists and includes all known failure categories.
- [ ] Sample normalization handles JSON zipBase64 and real ZIP.
- [ ] ZIP entry checks normalize slash and backslash.
- [ ] Stale sample/source artifacts are detected.
- [ ] Old runner use is explicitly blocked or warned.
- [ ] Generated execution-pack includes runner hardening files.
- [ ] test/lint/build pass.
- [ ] Autonomous Completion Gate passes.
- [ ] releases/v0.3.2 exists with source ZIP, sample ZIP, SHA256, manifest, dogfood evidence.
- [ ] commit exists.
- [ ] tag v0.3.2 points to final commit.
- [ ] git status is clean.

## No-go

- Do not modify historical release directories.
- Do not push remote.
- Do not add SaaS/cloud/payment/API systems.
- Do not expand target AI adapters beyond existing Codex/Claude Code/Trae/Cursor in this version.
