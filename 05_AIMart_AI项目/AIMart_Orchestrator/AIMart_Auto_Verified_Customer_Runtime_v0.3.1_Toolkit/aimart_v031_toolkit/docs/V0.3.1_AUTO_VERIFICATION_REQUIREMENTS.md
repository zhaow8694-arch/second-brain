# V0.3.1 Auto Verification Requirements

This version turns manual post-run checks into automatic gates.

## Gates that must be automatic

- Git branch/status check
- Target tag check
- Release directory check
- Source ZIP check
- SHA256 check
- Sample execution-pack extraction
- Required common/runtime/scripts/agent_adapters/docs check
- Multi-adapter existence check
- Customer root START files check
- Customer runner check
- Customer delivery verification scripts check
- Historical release protection check
- Local commit/tag freeze check

## Expected result

The runner must show PASS or FAIL. The user should not need to run PowerShell verification commands manually after the task finishes.
