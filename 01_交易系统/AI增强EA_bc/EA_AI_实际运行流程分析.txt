## ⚡ 实时运行流程

### OnTick() 频率控制
```mql4
static int tick_count = 0;
tick_count++;

// 平仓检查 - 每5个tick (最高频率)
if(tick_count % 5 == 0) {
    close_manager.CheckAndCloseOrders();
}

// 交易逻辑 - 每10个tick (AI调用频率)
if(tick_count % 10 == 0) {
    trade_executor.ExecuteTradingLogic();
}

// 锁仓管理 - 每20个tick (低频)
if(EnableLockManagement && tick_count % 20 == 0) {
    risk_manager.ManageLockedPositions();
}

// 状态检查 - 每100个tick (最低频率)
if(tick_count % 100 == 0) {
    trade_executor.CheckTradingStatus();
}
```

## 🎯 交易决策流程

### ExecuteTradingLogic() 执行顺序
```mql4
1. 更新账户信息
   money_manager.UpdateAccountInfo();

2. 检查市场状态
   bool market_suitable = market_monitor.IsMarketSuitable();

3. 获取AI预测
   ai_predictor.GetAIPrediction(ai_prediction, ai_confidence);

4. 综合决策
   int final_decision = MakeFinalDecision(ai_prediction, ai_confidence, has_ai_signal, market_suitable);

5. 信号确认检查
   if(EnableSignalConfirmation && final_decision != -1) {
       if(!ConfirmSignal(final_decision)) return;
   }

6. 检查渐进式锁仓触发
   risk_manager.CheckAndTriggerProgressiveLock(ai_prediction, ai_confidence);

7. 执行交易
   if(final_decision != -1 && market_suitable) {
       ExecuteOrder(final_decision);
   }
```

### 综合决策评分
```mql4
// MakeFinalDecision() 函数
权重分配:
- AI预测权重: 60%
- 技术分析权重: 20%
- 市场状态权重: 20%

评分计算:
1. 技术分析评分
   - MA交叉: ma_fast > ma_slow → buy_score += 0.2
   - RSI信号: rsi < 35 → buy_score += 0.1

2. 市场状态评分
   - market_score / 100.0 * 0.2

3. AI预测评分
   - 看涨: buy_score += 0.6 * ai_confidence
   - 看跌: sell_score += 0.6 * ai_confidence
   - 震荡: 两方向得分各减少 0.6 * ai_confidence * 0.3

决策阈值:
double decision_threshold = 0.2;
if(buy_score > 0.2 && buy_score > sell_score) return OP_BUY;
else if(sell_score > 0.2 && sell_score > buy_score) return OP_SELL;
else return -1;
```

## 🔚 平仓管理

### CheckAndCloseOrders() 执行顺序
```mql4
// 平仓优先级 (从高到低)
1. 400点盈利平仓 (最高优先级)
   if(profit_pips >= 400.0) {
       CloseOrder(OrderTicket(), "400点盈利平仓");
   }

2. 紧急止损 (已禁用)
   if(CheckEmergencyStopLoss(OrderTicket())) continue;

3. 亏损管理 (扛单模式)
   if(current_profit < 0 && CheckLossManagement(OrderTicket())) continue;

4. 技术指标平仓
   if(CheckTechnicalCloseCondition(OrderTicket())) continue;

5. 移动止损
   CTrailingStopManager::CheckTrailingStop(OrderTicket());
```

### 技术指标平仓条件
```mql4
// CheckTechnicalCloseCondition() 函数
1. MA交叉平仓
   - 买入单: ma_fast < ma_slow
   - 卖出单: ma_fast > ma_slow

2. RSI超买超卖
   - 买入单: rsi > RSIOverbought (95.0)
   - 卖出单: rsi < RSIOversold (5.0)

3. ADX趋势消失
   - adx < ADXThreshold (12.0)

注意: 扛单策略下，亏损订单不因技术指标平仓
```

### 扛单策略
```mql4
// CheckLossManagement() 函数
if(EnableHoldStrategy) {
    // 扛单范围内 (10000点以内) - 坚持持有
    if(loss_pips <= MaxHoldLossPips) {
        return false; // 不平仓，继续扛单
    }
    
    // 超过扛单极限时的处理
    if(loss_pips > MaxHoldLossPips) {
        if(HasReversalSignal(ticket)) {
            return false; // 有反转信号，继续扛单
        } else {
            CloseOrder(ticket, "扛单极限平仓");
            return true; // 强制平仓
        }
    }
}
```

## 🔒 锁仓系统

### 渐进式锁仓触发条件
```mql4
// CheckAndTriggerProgressiveLock() 函数
锁仓触发点:
- 第一层: 1500点亏损 (LockLevel1)
- 第二层: 2500点亏损 (LockLevel2)
- 第三层: 3500点亏损 (LockLevel3)
- 第四层: 4500点亏损 (LockLevel4)

锁仓执行:
- 手数: FixedLotSize * LockLotMultiplier (1.0倍)
- 间隔: 15分钟 (MinOrderInterval = 900秒)
- 记录: 保存到锁仓记录系统
```

### 锁仓单保护
```mql4
// 锁仓单特殊处理
1. 跳过所有平仓检查
2. 只允许分层解锁
3. 不执行紧急止损
4. 不执行亏损管理
5. 不执行技术指标平仓
```

### 分层解锁
```mql4
// 解锁盈利点
- 第一层: 200点盈利 (UnlockProfit1)
- 第二层: 300点盈利 (UnlockProfit2)
- 第三层: 400点盈利 (UnlockProfit3)
- 第四层: 500点盈利 (UnlockProfit4)
```

## 🎯 总结

### 系统特点
1. **完全扛单模式**: 删除所有回撤检查，10000点极限扛单
2. **渐进式锁仓**: 四层锁仓系统，分层解锁
3. **AI驱动决策**: 60%AI权重，实时预测
4. **智能平仓**: 400点盈利平仓，技术指标辅助
5. **频率控制**: 不同功能使用不同执行频率

### 核心优势
1. **AI与EA完美集成**: 文件共享方式，稳定可靠
2. **扛单策略**: 完全扛单模式，无回撤限制
3. **锁仓保护**: 四层渐进式锁仓，风险分散
4. **智能决策**: AI+技术分析+市场状态综合评分
5. **性能优化**: 频率控制，缓存机制，内存安全

### 风险控制
- **最大持仓**: 12个普通仓 + 4个锁仓单
- **扛单极限**: 10000点
- **锁仓触发**: 1500/2500/3500/4500点
- **盈利平仓**: 400点
- **点差控制**: < 50点

这个系统是一个高度集成的AI驱动交易系统，采用完全扛单策略配合渐进式锁仓保护，实现了稳定可靠的自动化交易。
