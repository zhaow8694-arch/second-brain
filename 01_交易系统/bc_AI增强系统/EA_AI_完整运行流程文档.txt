## ⚡ 实时运行流程

### OnTick() 执行频率控制
```mql4
static int tick_count = 0;
tick_count++;

// 平仓检查 - 每5个tick (最高频率)
if(tick_count % 5 == 0) {
    close_manager.CheckAndCloseOrders();
}

// 交易逻辑 - 每10个tick (AI调用频率)
if(tick_count % 10 == 0) {
    trade_executor.ExecuteTradingLogic();
}

// 锁仓管理 - 每20个tick (低频)
if(EnableLockManagement && tick_count % 20 == 0) {
    risk_manager.ManageLockedPositions();
}

// 状态检查 - 每100个tick (最低频率)
if(tick_count % 100 == 0) {
    trade_executor.CheckTradingStatus();
}
```

## 🎯 交易决策流程

### 1. AI预测读取
```mql4
// GetAIPrediction() 函数
1. 检查缓存时间 (5秒缓存)
2. 读取ai_prediction.txt文件
3. 解析预测信号和置信度
4. 更新缓存信息
```

### 2. 综合决策评分
```mql4
// MakeFinalDecision() 函数
权重分配:
- AI预测权重: 60%
- 技术分析权重: 20%
- 市场状态权重: 20%

评分计算:
1. 技术分析评分
   - MA交叉: ma_fast > ma_slow → buy_score += 0.2
   - RSI信号: rsi < 35 → buy_score += 0.1

2. 市场状态评分
   - market_score / 100.0 * 0.2

3. AI预测评分
   - 看涨: buy_score += 0.6 * ai_confidence
   - 看跌: sell_score += 0.6 * ai_confidence
   - 震荡: 两方向得分各减少 0.6 * ai_confidence * 0.3
```

### 3. 决策阈值
```mql4
double decision_threshold = 0.2;

if(buy_score > 0.2 && buy_score > sell_score)
    return OP_BUY;
else if(sell_score > 0.2 && sell_score > buy_score)
    return OP_SELL;
else
    return -1;  // 不开仓
```

## 🛡️ 风险控制流程

### 1. 建仓前检查
```mql4
// CanOpenNewOrder() 函数
1. 点差检查: MarketInfo(Symbol(), MODE_SPREAD) < MaxSpreadPips
2. 开仓数量检查: CountOpenOrders() < MaxOpenOrders
3. 建仓频率检查: CanPlaceNormalOrder()
4. 方向检查: HasSameDirectionOrder()
```

### 2. 渐进式锁仓管理
```mql4
// CheckAndTriggerProgressiveLock() 函数
锁仓触发条件:
- 第一层: 亏损1500点
- 第二层: 亏损2500点
- 第三层: 亏损3500点
- 第四层: 亏损4500点

锁仓执行:
- 手数: FixedLotSize * LockLotMultiplier
- 间隔: 15分钟 (MinOrderInterval)
- 记录: 保存到锁仓记录系统
```

### 3. 智能平仓
```mql4
// CheckAndCloseOrders() 函数
平仓条件:
1. 技术指标平仓

2. 移动止损
   - 基于ATR的动态止损
   - 倍数: TrailingStopMultiplier

3. 锁仓解锁
   - 分层盈利解锁
   - 智能解锁机制

│  市场数据   │───►│ market_data │───►│   AI服务    │

                   └─────────────┘           │
                                              ▼
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│   MT4       │    │   文件      │    │   Python    │
│  交易决策   │◄───│ ai_prediction│◄───│  模型预测   │
└─────────────┘    │   .txt      │    └─────────────┘
                   └─────────────┘
```

### 详细数据流
1. **MT4 → 文件**: 每10个tick写入market_data.csv
2. **文件 → AI**: Python监控文件变化，立即预测
3. **AI → 文件**: 预测结果写入ai_prediction.txt
4. **文件 → MT4**: EA读取预测结果，进行交易决策
