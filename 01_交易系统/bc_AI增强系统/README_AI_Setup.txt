# EA专用Transformer模型训练与部署指南

## 🎯 概述

这是一个专门为您的AI增强风险管理EA设计的Transformer模型，完全基于EA代码需求进行了深度定制。

### 🔑 核心特性

- **完美对接EA**: 输入输出格式完全匹配EA的AI模块
- **技术指标对齐**: 使用与EA相同的MA、RSI、ATR、ADX等指标
- **三分类预测**: 0=看跌, 1=震荡, 2=看涨 (对应EA代码)
- **置信度输出**: 提供0-1的置信度评分
- **实时服务**: 持续监控文件变化，提供实时预测

## 📋 环境要求

### Python 依赖
```bash
pip install torch pandas numpy scikit-learn ta joblib
```

### 系统要求
- Python 3.8+
- CUDA支持(可选，用于GPU加速)
- 至少8GB内存
- 足够的存储空间(模型大小约50MB)

## 📊 数据准备

### 1. 数据格式要求
您的数据文件需要包含以下列：
```csv
time,open,high,low,close,volume
2024-01-01 00:00:00,2000.50,2001.20,1999.80,2000.90,1250
2024-01-01 01:00:00,2000.90,2002.10,2000.20,2001.50,980
...
```

### 2. 数据质量要求
- **最少数据量**: 建议至少5000个数据点
- **时间连续性**: 数据应该按时间顺序排列
- **数据完整性**: 不应有过多缺失值
- **时间格式**: 支持多种时间格式，会自动解析

## 🔧 模型架构详解

### Transformer设计
```python
# 模型参数
- 输入维度: 自动检测(通常60-80个特征)
- 模型维度: 128
- 注意力头数: 8
- 编码器层数: 6
- 序列长度: 50 (与EA一致)
- 分类数: 3 (看跌/震荡/看涨)
```

### 特征工程
模型使用与EA完全对应的技术指标：

**基础特征**
- 价格收益率、高低比、价格范围
- 成交量价格乘积

**技术指标**
- MA(5,20,50,200) - 对应EA中的ma_fast, ma_slow, ma_long
- RSI(14) - 对应EA中的RSI指标
- ATR(14) - 对应EA中的ATR动态止损
- ADX(14) - 对应EA中的趋势强度检查
- MACD - 额外的趋势确认

**市场状态**
- 波动率分析 - 对应EA中的市场监控
- 成交量分析 - 对应EA中的成交量评分
- 支撑阻力距离 - 对应EA中的关键位检查

**时间特征**
- 小时、星期几
- 交易时间标识 - 对应EA中的时间过滤

## 📈 性能优化建议

### 1. 训练优化
- **数据质量**: 使用高质量、无噪声的历史数据
- **标签平衡**: 确保三个类别(看跌/震荡/看涨)数据平衡
- **特征选择**: 可以根据重要性调整特征
- **超参数调优**: 根据数据特点调整学习率、批次大小等

### 2. 推理优化
- **GPU加速**: 如有NVIDIA显卡，启用CUDA加速
- **缓存机制**: AI服务内置5分钟缓存，避免重复计算
- **文件监控**: 1秒检查间隔，平衡实时性和性能

### 3. 模型调优
```python
# 可调整的关键参数
future_periods = 5      # 预测未来几个周期
threshold = 0.002       # 涨跌判断阈值(0.2%)
sequence_length = 50    # 输入序列长度
d_model = 128          # 模型维度
num_layers = 6         # Transformer层数
```

## 🔍 故障排查

### 常见问题

**1. 模型加载失败**
```
❌ 模型文件不存在: best_trading_model.pth
```
解决: 先运行训练流程生成模型文件

**2. 数据格式错误**
```
❌ 数据文件缺少必要列: ['time', 'open', 'high', 'low', 'close', 'volume']
```
解决: 检查CSV文件列名和格式

**3. 特征维度不匹配**
```
⚠️ 缺少特征: {'ma_200', 'adx'}
```
解决: 通常是数据点不足，需要至少200个数据点计算MA200

**4. 内存不足**
```
RuntimeError: CUDA out of memory
```
解决: 减少batch_size或使用CPU模式
