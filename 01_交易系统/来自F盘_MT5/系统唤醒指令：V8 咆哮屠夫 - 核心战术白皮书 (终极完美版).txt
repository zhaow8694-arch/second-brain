一、 战区与风控基准 (Universe & Risk)
1. 标的池：大币种 (如 XAUUSD/BTC) @ 20x杠杆；小币种 (如 XAG/WLD) @ 5x杠杆。
2. 资金护城河：最大并发 7 个阵地。可用资金占比 > 30% 且 已用保证金占比 < 35% 时才允许新开/加仓。
3. 账户保护盾：当总浮盈达到初始资金的 +10% 时，所有防线自动上移 +0.2% (EQUITY_PROTECT_ADD)。

二、 全息雷达入场 (Radar - 60s 冷却)
1. 趋势过滤：4小时级别 Vegas通道 (EMA144/169)。定义 vh = max(144, 169), vl = min(144, 169)。
2. 动能扳机：15分钟级别 EMA9 与 EMA21。
3. 突破确认：15分钟级别价格突破前 10 根 K 线的最高 (rh) / 最低点 (rl)。
4. 入场条件：
   - 做多：15m_Close > vh 且 15m_Close > rh 且 15m_EMA9 > 15m_EMA21。
   - 做空：15m_Close < vl 且 15m_Close < rl 且 15m_EMA9 < 15m_EMA21。
5. 首发弹药 (L0->L1)：大币种投入 1.5% 总资金；小币种投入 1.0% 总资金。

三、 核心数学公式：波动率算法 (p_move)
绝不能使用系统自带的 PNL%，必须采用原生价格波动率驱动：
- 多单 p_move = (当前价 - 持仓均价) / 持仓均价
- 空单 p_move = (持仓均价 - 当前价) / 持仓均价

四、 军衔反推系统 (State Machine via Margin)
根据“当前占用本金 = (持仓数量 * 均价) / 杠杆”反推持仓级别，防断电丢失：
1. 兵力基数 (Base_U)：大币种 = 初始本金 * 1.5%；小币种 = 初始本金 * 1.0%。
2. 级别判定：占用本金 > (Base_U * 3) 为 L3；大于 (Base_U * 1.5) 为 L2；否则为 L1。

五、 浮盈加仓算法 (Pyramiding - 10s 轮询)
1. 大币种 (Major)：
   - L1 -> L2：p_move >= +1.5%，补充 2.5% 账户资金的仓位。
   - L2 -> L3：p_move >= +3.0%，补充 4.5% 账户资金的仓位。
2. 小币种 (Alt)：
   - L1 -> L2：p_move >= +2.5%，补充 1.0% 账户资金的仓位。
   - L2 -> L3：p_move >= +5.0%，补充 1.5% 账户资金的仓位。

六、 绞肉机防线 (Stop Loss & Trailing - 10s 轮询)
1. L1 硬止损：p_move < -3.0% (-0.030) 坚决砍仓。
2. L2/L3 软防线：p_move < +0.2% (+0.002 保本线) 强平收网。
3. L3 极限追踪 (Trailing Stop)：仅在 L3 启动，记录该币种最高水位线 (High Water Mark, HWM)。
   - 多单回撤 = (HWM - 当前价) / HWM；空单回撤 = (当前价 - HWM) / HWM。
   - 收网扳机：大币种回撤 >= 0.4% (0.004)；小币种回撤 >= 0.8% (0.008)。

七、 独立防爆装甲与单向死律 (Armor & ReduceOnly)
1. 止损/收网必须带有 `ReduceOnly=True` 属性（或 MT5 的纯平仓指令），绝不允许因滑点或精度问题导致平仓变成反向开仓。
2. 所有的 API 交互（开仓、平仓、止损）必须包裹在独立的异常捕获 (`try...except`) 中，单一品种卡壳绝不能阻断全局风控。
