---

## 一、设计哲学

Z-Wei 体系的五大核心原则在本EA中得到完整贯彻：

| # | 原则 | EA实现 |
|---|------|--------|
| 1 | **市场不可预测** | 机械式信号触发，不依赖预测/AI，依靠概率优势 |
| 2 | **交易是选择而非预测** | 5层质量过滤，只选择确定性最高的结构 |
| 3 | **适应市场** | 自适应ATR缓冲、波动率过滤，动态匹配市场状态 |
| 4 | **分形自同构** | H4主信号 → H1自同构结构二次确认 |
| 5 | **放弃完整行情** | ATR移动止盈，分段获利，拒绝死扛 |

## 三、5层质量过滤详解

### [层1] MA200 + ADX 趋势方向过滤

**理论来源**: 威科夫方法 + 趋势追踪核心

- **做多**: 上一根收盘价必须在 MA200 上方（允许 ATR×0.5 动态缓冲）
- **做空**: 上一根收盘价必须在 MA200 下方
- **ADX ≥ 20**: 确保市场处于趋势状态，拒绝震荡噪音

```
参数: InpUseMA200Filter=true, InpMA200BufferATR=0.5
      InpUseADX=true, InpADXThreshold=20.0
```

### [层2] K线实体占比

**理论来源**: 《市场结构观察 #26-2-2》- 突破K线必须"干脆"

- 实体占比 = |Close - Open| / (High - Low)
- 默认阈值: ≥ 60%
- 确保突破有真实动能，而非试探性穿刺

```
参数: InpBodyRatio=0.60
```

### [层3] 单边反向影线惩罚

**理论来源**: 《市场结构观察 #26-2-2》- K线干脆度单边检测

- **做多**: 严控**上影线**（卖压在最后压制 → 多方未真正胜出）
- **做空**: 严控**下影线**（买盘在最后承接 → 空方未真正胜出）
- 默认: 反向影线 ≤ K线总长的 20%

```
参数: InpMaxOppositeShadow=0.20
```

### [层4] 危险K线过滤

**理论来源**: 《危险的K线》- FOMO追高是最常见的亏损源头

- 振幅 > N×ATR → **拒绝入场**
- 逻辑: 异常巨大的K线 = 订单失衡(FVG) + 动能过度透支 + 可能是反转极点
- 默认: 2.5×ATR

```
参数: InpMaxCandleATR=2.5
```

### [层5] 点火与跟随确认

**理论来源**: 《点火与跟随》- 必须形成市场共识

- **默认关闭** (InpRequireFollowThrough=false)
- 开启后: 突破K线后需后续K线创极值确认跟风盘
- 3根K线内无跟随 → 放弃信号

```
参数: InpRequireFollowThrough=false, InpFollowThroughBars=3
```

## 四、混合入场信号: MACD + ZigZag BoS

### MACD柱状图翻转

- **做多**: 柱状图由负翻正 (hist[2] < 0 → hist[1] > 0)
- **做空**: 柱状图由正翻负 (hist[2] > 0 → hist[1] < 0)

### ZigZag 结构突破 (BoS)

- **看涨BoS**: 最近3个ZigZag高点呈下降趋势(Lower Highs) → 价格突破最近高点
- **看跌BoS**: 最近3个ZigZag低点呈上升趋势(Higher Lows) → 价格跌破最近低点
- **备用方案**: ZigZag指标不可用时，自动使用价格动作摆动点检测

### 混合逻辑

```
IF MACD翻转 AND BoS结构确认 THEN 生成信号
ELSE 无信号
```

## 五、多周期分形确认

**理论来源**: 《分形几何思维解读市场》- 结构自同构性

| 级别 | 周期 | 角色 |
|------|------|------|
| 主周期 | H4 | 信号生成 |
| 下级周期 | H1 (可调) | 分形确认 |

H4信号必须满足:
1. H1 MACD方向与H4一致 (InpRequireLowerMACD=true)
2. (可选) H1也出现BoS结构 (InpRequireLowerBoS=false)

## 六、风险管理

### ATR动态止损
- 止损 = ATR(14) × 1.5
- 动态适应市场波动率，高波动=宽止损，低波动=紧止损

### 固定百分比风险
- 每笔最大亏损 = 账户余额 × 0.5%
- 手数自动根据止损距离计算

### 移动止盈
- 启动条件: 浮盈 ≥ ATR × 2.0
- 移动步长: ATR × 1.5
- 每根H4 K线检查一次，绝不回撤利润

## 八、回测建议

### 对比测试方案

| 组别 | 配置 | 目的 |
|------|------|------|
| A组 (基准) | 关闭BoS、关闭分形、仅MACD+实体 | 基线性能 |

- 总交易次数: 完整版应显著减少
- 胜率: 每加一层过滤应有所提升
- 最大回撤: 最关键指标
- 平均盈亏比: 应>1.5
- 利润因子: 应>1.3

### 建议测试周期
- 2018-2025 (跨牛熊完整周期)
- XAUUSD H4, 每Tick模式

## 九、注意事项

1. **ZigZag依赖**: 首次使用需确保MT5自带ZigZag指标已编译 (`Examples\ZigZag`)。如果不可用，EA会自动使用价格动作摆动点检测。

2. **信号稀疏性**: 5层过滤在H4周期下信号较少（预计每月3-8笔），这是设计意图，不是Bug。Z-Wei体系的核心就是"狙击手"式的耐心等待。

3. **经纪商时区**: 时间过滤基于服务器时间，不同经纪商的H4 K线开盘时间可能不同。

4. **黄金特性**: XAUUSD波动率远高于外汇对，InpMaxCandleATR=2.5是保守设置。在极端行情（如非农、CPI）可能出现无法入场的情况——这符合Z-Wei体系"无法分类就不参与"的原则。
