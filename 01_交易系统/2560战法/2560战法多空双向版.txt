二、信号确认机制与市场环境（补充缺口1、3）
信号确认机制：所有交易信号必须在K线收盘时确认（OnBar机制），仅在新K线开盘的第一跳判断上一根已收盘K线的状态来触发信号，严禁K线未走完时实时开仓，杜绝信号闪烁。
市场环境判定：
多头环境：Close[1] > MA25[1] → 只允许做多（Buy）
空头环境：Close[1] < MA25[1] → 只允许做空（Sell）
多空切换处理：当市场环境发生切换时，必须先平掉所有反向持仓，再等待新的顺势开仓信号出现后方可开仓。严禁多空双向锁仓对冲。
三、多头交易逻辑（Buy）
做多开仓（放量进场）：K1收盘价突破MA25上方（Close[2] < MA25[2] 且 Close[1] > MA25[1]），同时VOL5向上穿越VOL60形成量能金叉，且当前多头持仓数 = 0 → 执行Buy开仓。
做多加仓（缩量加仓/缩量低吸）：处于多头环境，价格回调至MA25附近（距离 < Inp_Price_Pullback_ATR × ATR），满足以下任一量能条件，且持仓数 < Inp_Max_Orders → 执行Buy加仓：
条件A（均量线粘合）：|VOL5 - VOL60| / VOL60 < Inp_Vol_Sticky_Ratio
条件B（单日缩量）：VOL5 > VOL60，但 Volume[1] < VOL60[1]
多头平仓（放量离场/趋势破坏）：
量能异常：VOL5 < VOL60，且 Volume[1] > Inp_Abnormal_Vol_Ratio × VOL60（诱多信号）→ 平所有多单
趋势破坏：Close[1] < MA25[1] → 平所有多单
四、空头交易逻辑（Sell）
做空开仓（放量进场）：K1收盘价跌破MA25下方（Close[2] > MA25[2] 且 Close[1] < MA25[1]），同时VOL5向上穿越VOL60形成量能金叉，且当前空头持仓数 = 0 → 执行Sell开仓。
做空加仓（缩量加仓/缩量高空）：处于空头环境，价格反弹至MA25附近（距离 < Inp_Price_Pullback_ATR × ATR），满足以下任一量能条件，且持仓数 < Inp_Max_Orders → 执行Sell加仓：
条件A（均量线粘合）：|VOL5 - VOL60| / VOL60 < Inp_Vol_Sticky_Ratio
条件B（单日缩量）：VOL5 > VOL60，但 Volume[1] < VOL60[1]
空头平仓（放量离场/趋势破坏）：
量能异常：VOL5 < VOL60，且 Volume[1] > Inp_Abnormal_Vol_Ratio × VOL60（诱空信号）→ 平所有空单
趋势破坏：Close[1] > MA25[1] → 平所有空单
五、止损止盈与资金管理（补充缺口5、8）
ATR动态止损止盈：
做多：止损 = 开仓价 − Inp_StopLoss_ATR × ATR；止盈 = 开仓价 + Inp_TakeProfit_ATR × ATR
做空：止损 = 开仓价 + Inp_StopLoss_ATR × ATR；止盈 = 开仓价 − Inp_TakeProfit_ATR × ATR
移动止损：当浮动盈利达到 Inp_Trailing_Start_ATR × ATR 时，止损移至成本价（保本），此后随价格有利移动同步跟进，锁定利润。
仓位计算（固定风险比例）：
开仓手数 = (账户余额 × Inp_Risk_Percent%) / (止损点数 × 每点价值)
计算结果按平台最小手数步长向下取整修正；若未启用，则使用 Inp_Lot_Size 固定手数。
六、交易时间过滤（补充缺口4）
允许交易时段：08:00 – 22:00（平台服务器时间），时段外不触发新开仓，但平仓与移动止损继续运行。
周五强制平仓：可选开关，开启后EA在周五22:30自动平掉所有持仓，规避周末跳空风险。
七、K线实体过滤（防假突破）
突破MA25的K线必须满足以下条件，否则不触发开仓：
K线实体占比（实体大小 / K线总长度）> 60%，拒绝十字星和长影线信号
突破K线的收盘价需明显越过MA25（超过 0.5 × ATR），拒绝勉强触碰
八、最大回撤熔断（补充缺口9）
当账户净值从最高点回撤超过设定阈值（如15%）时，EA自动停止所有新开仓指令，并发送报警通知。待人工确认后方可重新启用，防止连续亏损扩大。
