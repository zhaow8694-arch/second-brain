# /vault-lint — Vault 健康体检

扫描整个 Obsidian Vault，诊断以下问题并输出报告：

## 检查清单

### 1. 🧹 孤立笔记（无任何链接的笔记）
- 扫描所有 .md 文件
- 找出 `file.inlinks` 和 `file.outlinks` 均为 0 的笔记
- 排除：Templates/、附件/、Excalidraw/、Daily/、Periodic/、索引文件、CLAUDE.md
- 输出：列表 + 建议归类到哪个文件夹

### 2. 🔗 死链（指向不存在文件的 [[链接]]）
- 扫描所有 `[[wikilink]]` 
- 检查目标文件是否存在
- 输出：源文件 → 死链目标

### 3. 🏷️ 缺少 frontmatter 的笔记
- 检查是否有 `tags` 和 `date` 字段
- 排除：模板文件、自动生成的文件
- 输出：文件列表

### 4. 📂 可归档的旧笔记
- 查找超过 90 天未修改的笔记
- 排除系统文件和活跃项目文件
- 输出：建议归档列表

## 输出格式
生成一份 `99_收件箱/Vault体检报告-YYYY-MM-DD.md`，内容包括：
- 总览数字（总笔记数、健康笔记数、问题数）
- 四类问题的详细列表
- 自动修复建议（能自动修的标注 ✅，需人工判断的标注 🔧）

## 自动修复
对以下问题自动处理，不需要询问：
- 补充缺失的 `date` frontmatter（用文件创建日期）
- 重复标签合并（大小写归一化）
- 明显死链（目标文件名错别字 → 自动修正）

## 规则
- 不修改 `08_杂项/`、`07_数据库/`、`.obsidian/`
- 不删除任何文件
- 批量修改前报告数量
