# /vault-eod — 日终复盘

每日收盘后运行，整理当天的工作和交易：

## 步骤

### 1. 对比计划 vs 实际
- 读取今日 Daily Note 的「今日重点」
- 统计完成率
- 未完成项 → 写入明天的日记（待 /vault-morning 接手）

### 2. 交易复盘（如有交易记录）
- 逐条对照 CLAUDE.md 中的「交易规则检测清单」
- 统计：胜率、盈亏、违规次数
- 新教训 → 建议是否写入 CLAUDE.md 规则清单
- 输出复盘摘要

### 3. 整理收件箱
- 扫描 `99_收件箱/` 的新文件
- 按 CLAUDE.md 的分类规则自动归类
- 更新 `📖 知识库索引总表.md` 归档记录

### 4. 会话沉淀
- 生成本次会话摘要
- 写入 `工作记录.md`
- 重要发现/决策 → 写入 claude-mem 持久记忆

### 5. 输出日终简报
```
🌙 日终复盘 — YYYY-MM-DD

✅ 计划完成：X/Y 项
📊 今日交易：X 笔，胜率 X%，盈亏 +$X
⚠️ 规则违规：X 次（规则①趋势线未确认 / 规则③缺共振）
🔧 已修复：X 项 vault 问题
📥 收件箱：X 个新文件 → 已分类到 XX/
💡 新教训：...（建议加入 CLAUDE.md）
📌 移交明天：X 项未完成任务
```

## 规则
- 收盘后触发（或用户随时手动触发）
- 重点在交易规则检测，比晨间更详细
- 归档操作要更新索引表
