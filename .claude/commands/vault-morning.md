# /vault-morning — 晨间启动

快速启动每日工作流：

## 步骤

### 1. 读取昨天的 Daily Note
- 打开 `Daily/YYYY-MM-DD.md`（昨天日期）
- 如果没有昨天的日记，直接跳到步骤 3

### 2. 检查昨日遗留
- 找出所有未完成的任务 `- [ ]`
- 判断哪些需要今天继续 → 迁移到今天的日记
- 超过 3 天未完成的 → 标记 ⚠️ 询问是否放弃/延期
- 交易相关遗留 → 特别标注，检查是否有未平仓逻辑

### 3. 生成今日日记
- 使用 `Templates/Daily.md` 模板
- 自动填入：日期、昨天盈亏总结（如有）、迁移的未完成任务
- 检查日历：今天是否有重要事件/数据发布（非农、利率决议等）

### 4. 输出晨间简报
```
🌅 晨间简报 — YYYY-MM-DD

📊 昨日交易：X 笔，胜率 X%，盈亏 +$X
📋 迁移任务：X 项
⚠️ 今日关注：非农数据 / 利率决议 / ...
🎯 今日建议重点：
  1. ...
  2. ...
```

## 规则
- 简洁高效，晨间不要长篇大论
- 交易日优先提醒市场事件
- 非交易任务不自动迁移，询问用户
