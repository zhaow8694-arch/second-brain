# Vault 维护技能

## 可用命令

### `/vault-morning` — 晨间启动
- 读取昨日日记，迁移未完成任务
- 生成今日日记
- 输出晨间简报

### `/vault-eod` — 日终复盘
- 对比计划 vs 实际
- 交易复盘（逐条对照规则）
- 整理收件箱
- 更新工作记录和索引

### `/vault-lint` — Vault 体检
- 检查孤立笔记、死链、缺失 frontmatter
- 自动修复可修复项
- 生成体检报告

## 自动化规则
1. 每次新增笔记 → 检查是否需要更新索引
2. 每次修改笔记 → 检查 dead link
3. 收件箱文件超过 3 天未分类 → 提醒归档
4. 工作记录每次会话必须更新
