# 教培转研学决策框架

> 核心判断：教培机构**不必都转型研学，但必须补一条"体验式教育产品线"**——研学的本质是场景化教育，不是改行旅行社。市场三年涨 65%（1469亿→1790亿→2422亿）但多数机构没赚到钱，因为都挤在"旅游账户"里比价。

## 一、决策前提：转 or 不转

**转型三大价值**（补产品线而非转行）：
1. 提升信任——家长在真实场景看到孩子表现，粘性翻倍
2. 收入结构——周末半日营/一日营/寒暑假/五一十一，第二条增长曲线
3. 差异化——作文机构做户外写作、英语机构做城市采访、素养机构做项目式研学

**转型四问**（任一答不出就缓）：
- 原有课程适合延伸到什么场景？
- 家长愿为什么样的体验买单？
- 团队能否稳定交付？
- 研学能否反哺主业？
- ⚠️ 没有课程目标/活动设计/安全管理/执行流程/家长反馈/转化流程的研学，只会消耗口碑

## 二、行业结构：波特五力全挤压（结构性不性感）

| 力量 | 现状 |
|:-----|:-----|
| 新进入者 | 旅行社资质+兼职大学生+大巴即可入局（全国 2.9 万家企业、近半五年内新开） |
| 同行绞杀 | 你 598 他 498，真研学打不过"旅游+讲座" |
| 替代品 | 家长预算 1 万个出口：自家带娃/补习班/夏令营/一个 iPad |
| 客户 | 学校招标三家比价、家长五家咨询 |
| 供应商 | 酒店/大巴/门票涨价，售价被价格战定死 |

**破局只有两条路（微笑曲线两端）**：左端自研课程、自养导师、做 IP 抄不走的内容；右端做用户和品牌，让客户"为你而来"而不是"为便宜而来"。

## 三、四个核心工具

### 1. 翻译工具（感知杠杆）——研学利润的真正来源
顾客只为感知价值付费：把普通资源"翻译"成家长买得起的样子。
- 翻译对照：大巴→研学专属车队 / 大锅饭→营养食育课程 / 农家乐通铺→星空下的集体生活 / 拔河→美式营地团队工作坊 / 拔萝卜→种子到餐桌劳动教育 / 兼职学生→985 学霸天团 / 群发照片→成长过程性影音档案 / 两毛的章→权威认证研学证书
- 数字实证：成本 1800 元，旅行社卖 2380（毛利 10 个点），**翻译后卖 4980**——多出的 2600 全是"翻译费"，成本仅手册 20 元+证书 5 元+课程研发摊到每人不到 50 元
- 铁律：**感知价值可高于成本，但不能高于交付**——交付跟不上叫诈骗；"包装是骗人的，翻译是值钱的"

### 2. 心理账户（塞勒 2017 诺奖）——把产品从旅游账户挪进教育账户
- 家长的钱分账户：教育账户痛感低甚至反向（花越多越安心：8000 元英语课刷卡不眨眼），旅游娱乐账户痛感高（800 块研学营问题一堆）
- 研学是教育产品，却大多被放进旅游账户，**跟成本结构不同的旅行社比价必输**
- 挪账户三步：
  1. **换参照物**——不跟旅行社比价格、跟补习班比时长（3980=两个月英语课时费换一次记一辈子的户外实践课）；线路→课程大纲、导游→导师、行程→课表、打卡→课题
  2. **给凭证**——证书/研究性学习报告/综评素材/作品集（给不了凭证，家长只能按"玩了一天"估值）
  3. **让孩子回家说"我们做了个课题"而非"玩了一天"** → 复购自己来

### 3. PEST 四维追问——外部变化先问"谁付钱、谁决策、谁能拿走利润"
- 政策：教育服务化——红利先变合规成本，再变专业企业的竞争门槛
- 经济：人均每次消费降 6%（2025 出游 65.22 亿人次、6.3 万亿）→ **本地短半径、低决策成本的半日营/一日营**更易形成稳定模型
- 社会：47% 家长把综合能力当培养重点（仅 24% 选学科基础）；为真实场景能力付费
- 技术：AI 不消灭研学，只消灭**靠讲知识、倒卖资源差赚钱**的研学

### 4. 问题思维——AI 时代好答案变便宜，好问题变昂贵
- 浅层问题（什么线路最火/哪有便宜基地）AI 回答得更好；**深层问题**（为什么老客户复购越来越少/同样线路别家 899 我家 599 还卖不好/AI 完成 80% 知识传递后研学的不可替代价值是什么）决定企业走向
- 德鲁克：效率是把事情做对，有效是做正确的事情
- 带团队少问"方案怎么做"，多问"我们到底在解决什么问题"

## 四、人才与 AI 时代（靠谁交付）

| 群体 | 逻辑 | 数据 |
|:-----|:-----|:-----|
| 师范生（1270 万毕业生） | 考编与教培拥挤，研学是**第三条路**——学的东西没浪费，只是应用场景变了（语文→人文类、生物→自然教育、体育艺术→户外美育） | 收入不再以时间计费：导师→课程负责人→项目经理→产品负责人 |
| 文科生 | "对着屏幕的文科被 AI 代替，对着人的文科持续涨价"——AI 代替的是编辑/翻译/行政 | 研学旅游指导师已出国家职业标准（人社部 4 月）；北京导师月薪 8000-10000 |
| 导游（Countess Travel） | 卖线路→**卖能解释世界的人**；3.5 小时梵蒂冈讲解 925 美元，专家卖"理解"而非"信息" | 60+ 城市、25 万场讲解、讲师八成硕博；价格分层：19 美元音频获客→百美元拼团做规模→千美元私人团做利润 |
| 学历 vs 技能 | 韩国半导体技校生 96.4% 直接就业、17 岁拿三星 offer（平均年薪 70 万人民币），大学以上失业 48 万——"赢的不是努力，是位置" | 职业体验=给孩子做"**人生尽调**" |
| AI 开源（K3 开源） | AI 没抢研学人的饭碗，抢的是琐事的饭碗（宣传物料/行程表/成长报告三件事立刻可用 AI） | 每轮技术革命都是"会用技术的人淘汰不会用技术的人" |

## 五、行动检查清单

- [ ] 定位是教育产品不是旅游产品（参照物=补习班，不是旅行社）
- [ ] 课程有目标、有教案、有评价、能复购（微笑曲线左端）
- [ ] 家长群经营成"信任存款"而非名单（微笑曲线右端）
- [ ] 每个活动给凭证（证书/报告/作品集）
- [ ] 孩子回家会说"我们做了个课题"
- [ ] 场景可被品牌冠名（2B 收入曲线）
- [ ] 行前通知里有破冰设计，导师会"带人"而非只"讲课"
- [ ] 主力交付者是专家型导师，不是大学生临时工
