# 量化策略的七大流派

> 能盈利的量化策略主流上就分 7 种：趋势跟随、均值回归、套利、统计套利、因子投资、高频交易、机器学习。没有哪种策略能通吃所有市场——趋势跟随怕震荡、均值回归怕单边、套利怕没空间、高频怕监管，真正赚钱的量化机构往往是**多策略组合**。

## 一、趋势跟随（Trend Following）

- **核心逻辑**：顺势而为，涨了买、跌了卖，不抄顶不抄底。趋势一旦形成就会自我强化。
- **数学/统计基础**：线性代数、概率论、时间序列分析（Time Series），进阶如 GARCH 模型；Python 主要用 Pandas、NumPy。
- **代表机构**：英仕曼（Man Group）旗下 Man AHL（趋势量化跑了 20 多年）；AKR 资本的 Helix 策略（方向性宏观 + 趋势跟随量化对冲，年回报约 18.6%）。
- **适合环境**：单边行情。
- **死穴**：震荡行情来回挨打。

## 二、均值回归（Mean Reversion）

- **核心逻辑**：与趋势跟随相反——涨多了卖、跌多了买，赌价格回到平均值。
- **数学/统计基础**：统计学。价格短期偏离均值，长期必然回归。例：沪深300 一年均值 4500 点、标准差 150 点，触 2 倍标准差（4500±300）即代表情绪极度贪婪（卖）或极度恐惧（买）。
- **代表机构**：GMT 资本旗舰基金（30 年平均年化 17%）；国内幻方、九坤等"量化四大天王"底层逻辑均涉及。
- **适合环境**：震荡行情。
- **死穴**：遇到大的单边行情很难赚钱。

## 三、套利（Arbitrage）

- **核心逻辑**：同一标的在不同市场价不同，便宜市场买、贵市场卖，赚取价差。理论风险低，但收益空间小，拼的是速度和成本。
- **数学/统计基础**：无需复杂模型，依赖基础设施与执行速度。例：加密币 BN 报价 6 万、OKX 报价 60100，同时一买一卖套 100 块价差。
- **代表机构**：Citadel、Two Sigma 极擅长；国内鸣石资产以期权套利为核心策略。
- **适合环境**：市场间价差出现时（任何行情均可，与方向无关）。
- **死穴**：容量有限、对竞价速度要求极高，普通投资者难以模仿。

## 四、统计套利（Statistical Arbitrage）

- **核心逻辑**：套利的升级版——不找同一资产的价差，而是找**一群相关资产**的稳定价格关系，谁偏离就做多弱的、做空强的，赚"关系修复"的钱。
- **数学/统计基础**：协整检验。例：茅台 ≈ 6×五粮液 + 3×泸州老窖（三支高端白酒股受同源需求/成本/政策影响）；茅台提价消息大涨 10%、价差偏离达历史 2 个标准差时，融券做空茅台、同时买入等量五粮液+老窖。
- **代表机构**：D.E. Shaw 1988 年率先把计算机技术应用于统计套利；Two Sigma 策略亦覆盖此领域。
- **适合环境**：资产相关性长期稳定的市场；与牛熊方向无关（市场中性）。
- **死穴**：需要极强建模能力，**模型风险（尾部风险）**高——一旦协整关系本身破裂即双杀。

## 五、因子投资（Factor Investing）

- **核心逻辑**：目前公募量化最主流的玩法。用估值、成长、动量等上百个因子给股票打分，选出综合得分最高的构建组合。
- **数学/统计基础**：多因子模型。里程碑事件：WorldQuant 发布 101 个 Alpha 因子。
- **代表机构**：国金量化多因子（曾获金牛奖）；华泰柏瑞、招商等也有类似产品。
- **适合环境**：适合规模相对较大的资金，容量大。
- **死穴**：因子可能失效、同质化竞争严重，Alpha 会被市场磨平。

## 六、高频交易（HFT）

- **核心逻辑**：毫秒甚至微秒级完成交易，赚极微小价差，主要靠**速度**而非预测涨跌——比别人快 0.01 秒发现并抹平价差。
- **数学/统计基础**：不靠股价预测，靠超高速传输与自动处理。例：同一公司 A 股 1502 / B 股折算 1500，0.01 秒内 A 股做空、B 股买入，价差收敛后平仓赚 2 块。价差只存在零点几秒，慢一拍就消失。
- **代表机构**：高盈量化高频基金（近三年收益超 200%）。
- **适合环境**：跨市场/跨交易所价差瞬间出现时；信息传递有延迟的市场结构。
- **死穴**：门槛高、竞争激烈、监管越来越严。

## 七、机器学习策略（Machine Learning）

- **核心逻辑**：最前沿方向——让 AI 在海量数据中自己发现规律、找因子，捕捉人脑发现不了的非线性关系。
- **数学/统计基础**：深度学习/非线性模型（黑箱 Black Box：只有输入→输出，逻辑不可解释）。
- **代表机构**：桥水推出 20 亿美元机器学习量化基金；AQR 转向让 AI 做决策；国内幻方是 AI 基金代表（2025 年收益均值约 56.55%）；平方和投资以机器学习为核心。
- **适合环境**：数据量大、非线性关系丰富的市场。
- **死穴**：黑箱不可解释、难以落地与风控归因。

## ⚡ 与现有体系的联系

| 七大流派 | Z-Wei 六规则 / SniperTrendEA 对应关系 |
|:---------|:--------------------------------------|
| **趋势跟随** | SniperTrendEA（5 层过滤趋势狙击）正是此流派。六规则中的①趋势线≥3 次确认、③共振≥2 信号、⑤不吃全段、⑥危险K线离场，全部是趋势跟随的入场/出场过滤器 |
| **震荡市空仓（规则④）** | **直接印证趋势跟随的死穴**——"趋势跟随怕震荡，震荡行情来回挨打"。SniperTrendEA 的震荡过滤层就是把这条死穴编码进系统 |
| **均值回归** | **与规则④"震荡市空仓"存在根本矛盾**：均值回归专吃震荡、怕单边，而 Z-Wei 体系视震荡市为禁入区。两者是互补的另一条腿，而非替代品；且单边行情下均值回归失效，恰好反向印证规则①（趋势确认前不逆势操作） |
| **统计套利** | 与规则③"共振"思想相通（关系修复靠多个资产相互印证）；市场中性、与方向无关，可作为组合中与趋势策略负相关的一条腿 |
| **套利 / 高频** | 依赖速度与基础设施，个人手工交易不可复制；印证"不模仿机构"的纪律 |
| **多策略组合** | 视频结论（真正赚钱的机构都是多策略组合）印证现有多 EA 并存思路（SniperTrendEA + 2560 战法 + 华尔街对冲互为补充），而非单策略梭哈 |

**核心启示**：Z-Wei 体系 + SniperTrendEA 本质是"趋势跟随 + 震荡市空仓"的严格纪律化实现——六规则正确识别了该流派唯一的死穴并主动规避；若未来要扩能力边界，均值回归/统计套利是方向性互补的下一块拼图。
