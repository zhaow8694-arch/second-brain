# AI Agent 与个人生产力实战

> 核心判断：对普通人，AI 的第一杠杆是 **vibe coding + 养 Agent**——不是学会编程，而是学会"把 AI 当人养"（soul/memory/skill 三件套）。但 Agent 化有数学边界：每步 95% 准确率的 20 步任务，成功率只有 36%——**拆短步骤 + 人工确认点**是把可靠率拉回 90% 以上的唯一办法。无状态模式（每次独立调用）比有状态模式便宜一个数量级，避开"平方成本诅咒"。

## 一、把 AI 当人养：Agent 的灵魂三件套

| 组件 | 作用 | 类比 |
|:-----|:-----|:-----|
| **Soul**（人格/指令） | 定义角色、语气、行为边界 | 人的性格与职业素养 |
| **Memory**（记忆） | 跨会话记住偏好、历史、上下文 | 人的长期记忆 |
| **Skill**（技能） | 可复用的专业流程/工具调用 | 人的肌肉记忆与专业能力 |

- 实证案例：**爱马仕智能体**（自主成长型 Agent）——被持续投喂使用反馈后，能力随使用时间自动增强；**饺子馆 Skill 在 GitHub 开源**——一个饺子馆老板一晚上 vibe coding 出自己的店专属 Skill
- 为什么有效：AI 的通用能力已经足够，**稀缺的是对特定场景的定制封装**——把"会 AI"变成"懂我的业务"

## 二、Agent 化的数学与工程约束

- **成功率诅咒**：单步 95% 准确 × 20 步 = 36% 总成功率 → 对策：**把任务拆成 3-5 步的短链 + 每步人工确认**，宁可多问一次
- **平方成本诅咒**：有状态 Agent 会话长度随时间平方增长 → 对策：**无状态模式**（每次独立调用、显式传入上下文），成本降低一个数量级
- **长任务入门**：10min Agent 做长任务——长任务成败在**检查点设计**，不在模型聪明程度
- **数据主权**：AI Agent 时代来了，但你的数据喂给了谁？→ 本地部署 / 私有知识库是 Agent 化前的必修课

## 三、工具栈全景（2026 年中实测）

| 工具 | 定位 | 一句话结论 |
|:-----|:-----|:-----------|
| Claude Code | 编程 Agent 旗舰 | 设计哲学=**渐进式披露**（一层层展示细节，人始终在环）；GitHub 史上最快 10 万星 |
| Pi Agent | 普通人向 Agent | **比 Codex 更适合非程序员**；Pi 打赢 Claude Code/Codex 靠的是把"人机协作"做得更自然 |
| Cursor | 编辑器 + token 优化 | 免费提升 5 倍使用量的终极技巧（缓存/上下文压缩） |
| MCP | Agent 能力扩展协议 | 小白一个人开发 AI 应用的第一入口：MCP + 模板 = 需求直通应用 |
| NotebookLM | 效率工具 | 文档问答/播客生成，最实用的"资料消化"工具 |
| 豆包/本地知识库 | 中文日常 + 隐私 | 还在用豆包聊天？搭本地 AI 知识库，数据不出机器 |

**个人 vibe coding 工具栈**（平民配置）：AI 编程助手 + 模板脚手架 + 云端部署（一键发布）+ 数据统计——一条龙 30 分钟出第一个产品。

## 四、一人公司打法：一年 30 个 AI 应用

- **挑战模型**：一人公司「挑战一年上线 30 个 AI 应用」——已产出：随手记（记录工具）、帮你回（i 人嘴替）、微信整理助手
- **选品逻辑**：一人公司如何选择赛道？→ 自己就是第一个用户 + 工具型/效率型（低交付、可订阅）
- **变现路径**：vibe coding 做的网站和应用怎么变现？→ 订阅制 > 广告 > 一次性买断；**微信客服 + AI**是当前最成熟的"一人公司产品模式"（私域即护城河）
- **避坑**：一人公司最大的内耗是"因不知道花时间试错"——先抄后超，模板化起步；税务等杂事用 AI 轻松搞定
- **协作形态**：人类和 Agent 在一个团队里如何协作？→ 人类定方向与验收，Agent 做执行与复盘——**验收是人的不可替代工作**

## 五、认知升级：从"用工具"到"当合伙人"

- **Clawdbot 创始人的 AI 方法论**：Agent 开发全过程的教训——先跑通再优化，KPI 用"任务完成率"不用"响应速度"
- **Agent 时代的信任基础设施**：当 Agent 开始替你花钱/发言，信任层（身份、权限、审计）成为新生意
- **Agent 时代 80% 的 App 即将消失**：GUI 时代落幕，对话框即入口——个人开发者的窗口期
- **渐进式披露哲学**（Claude Code）：让用户随时知道 Agent 在做什么、能随时接管——这是所有 Agent 产品的人机信任底座
