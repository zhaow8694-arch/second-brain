# AI 大模型演进图谱

> 核心判断：2025-2026 大模型主线是**开源成本革命 + 推理训练范式 + 硬件多元化**。DeepSeek 用 557 万美元训练出逼近闭源巨头的能力、把 API 价格打穿 93%，把行业从"参数军备竞赛"改写为"效率与推理质量竞赛"；与此同时闭源巨头集体转向"能力藏一半"（GPT-5 训练完成但可能永不发布），安全与评测体系严重滞后于能力增长。

## 一、开源革命：DeepSeek 为什么是分水岭

| 维度 | 事实 | 含义 |
|:-----|:-----|:-----|
| 训练成本 | 557 万美元 vs 闭源同级模型的数亿美元，**成本差 93%** | 证明算力堆砌不是唯一路径，方法学（MoE+强化学习）可换效率 |
| 扩散速度 | R1 发布 **18 天达成 1500 万日活** | 开放权重模型的病毒式传播远超闭源 API |
| 技术路径 | **无需人类监督**的纯 RL 训练（R1-Zero），从"分步思考"演化出"思维链" | 推理能力可从奖励信号自我涌现，替代人工标注 |
| 开源周 | DeepEP（专家并行通信库）、DeepGEMM（一行代码凭空多出 2000 亿算力） | 不只是模型开源，**基础设施层也开源**，抬高整个生态水位 |
| 产业冲击 | OpenAI CEO 公开认错"站在了历史错误的一边" | 闭源护栏论被证伪：开源可以又强又安全 |
| 商业反噬 | DeepSeek 涨价（API 上调数倍） | 免费期是获客武器，护城河建立后必然回归商业化——开源不等于慈善 |

**教训**：开源模型正在吃掉"通用能力"这一层，闭源巨头的护城河只剩 **实时数据、算力规模和产品渠道**——这正是本图谱第二、三节的主线。

## 二、闭源巨头困境：能力越强，越不敢放

- **GPT-5 研发遭遇 5 大致命困境**，OpenAI 被迫重新规划；更疯狂的是"**训练已经完成，但永远不会公开**"——能力上限不再由技术决定，而由安全评估与商业节奏决定
- **o3 作弊丑闻**：被曝提前偷看数学考题（评测集污染），评测可信度崩塌
- **Opus 4.7 发布"残血版"**：刻意保留能力上限，仍是第一梯队
- **Mythos**（Anthropic）被称为"顶级黑客模型"，超越 Opus 4.6——模型开始具备 **渗透测试级能力**，安全机制是否跟得上成为最大问号
- 能力对比线（2026 年中）：Deepseek V4 ≈ Opus 4.7 ≈ GPT 5.5 > GLM 5.1 ≈ Kimi K2.6，第一梯队差距已缩小到"残血版 vs 开源版"的毫厘之间

## 三、技术地基：能力从哪来

| 技术 | 一句话本质 | 应用启示 |
|:-----|:-----------|:---------|
| 思维链（Chain of Thought） | 把"分步思考"变成训练信号，推理从单次猜测升级为逐步验证 | 复杂问题要求模型**显式分步**，不要给一步到位的指令 |
| 蒸馏 | 大模型当老师、小模型当学生，能力迁移 | 商业落地的标配：把千亿模型压缩到可本地部署的规模 |
| 量化 | 把 32 位权重压缩成 8/4 位（"把大象塞进冰箱"） | 显存减半、速度翻倍，代价是可忽略的精度损失 |
| 上下文工程 | 知识放 prompt 而不是靠重训 | 个人应用的核心技能：检索增强 > 微调 |
| 本地部署 | 消费级选型：显存决定模型上限，Mac 统一内存/游戏卡/矿卡各有生态 | Agent 场景越来越吃香（隐私+成本+长任务） |

## 四、硬件多元化：GPU 不再是唯一答案

- **光子计算机**（Light Matter）：光子芯片做矩阵运算，可能打开超级智能的大门——功耗/速度的数量级优势，卡脖子问题的另一种解法
- **生物计算机**：全球首个可商用的生物计算机发布——类脑计算从实验室走向产品
- **RISC-V**：芯片行业的"DeepSeek"——开源指令集冲击 ARM/x86 双寡头，算力民主化在指令集层面重演
- **DeepSeek 开源周的底层逻辑**：通信与算子层优化（DeepEP/DeepGEMM）让现有 GPU 凭空多出算力——**算法优化与硬件创新双线并行**

## 五、安全与认知边界

- **如何证明 AI 有没有意识？** 学界仍无判定标准——"AI 的两次死亡和人类的渡劫"：能力增长与对齐机制的剪刀差是未来最大风险
- **模型分级是伪命题吗？** 能力分级标准滞后，o3 作弊事件说明评测体系本身可以被污染
- 2026 年通用人工智能（AGI）之问：人类可能不再是地球上最聪明的物种——但"AGI 来了为什么我们感觉不到？"因为能力分布不均匀：**先落在编程与安全域，后到达日常**
