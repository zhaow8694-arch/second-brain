# 技术分析与逆向执行：确认框架与极端机会

> 核心判断：技术分析是**概率工具，不是水晶球**——它的价值不在预测方向，而在给出"什么情况算确认、什么情况算失效"的刻度。多维度共振才进场（Never chase a breakout），极端情绪才是逆向出手的窗口，而财报/回测都只是"体检报告"——真正值钱的是执行与迭代。

## 一、技术分析确认框架（入场刻度）

- **多时间框架共振 = 高概率信号**：单一周期信号可能是噪音，周线+日线+小时线同向才是趋势真朋友
- **测量移动（Measured Move）**：量度盘整深度，从突破点投射目标位（NVDA 例：$700 → $900 → $1200+）——给"不吃全段"提供了客观的目标刻度
- **形态工具箱**：
  - **杯柄形态**：3 年大基底整理后的突破（NBIS $50 → $150+）
  - **W 底/双底**：最可靠的底部反转形态；道氏理论中**运输指数是领先指标**
  - **突破 + 回测**：健康回调到前阻力位 → 转化为新支撑 = 最好的二次进场点
- **均线系统**：8/21/200 日线识别趋势层级（短期情绪 / 中期趋势 / 长期方向）
- **RSI/MACD 背离**：牛背离 = 动能切换信号（与"动能分析四课"完全一致：背离是体检报告不是买卖信号）
- **成交量确认**：突破放量、回调缩量 = 健康；放量滞涨 = 危险
- **板块轮动顺序**：大科技(M7) → 中概股 → 中小盘 → 加密——资金流向有固定顺序，可用于判断行情阶段
- 金句：*"Never chase a breakout"*——等回测确认（= Z-Wei 规则 2"突破 K 线实体确认"的英文版）

## 二、逆向投资：极端才是机会

- **Michael Burry 启示**：1999 年住院医生年入 $33K，用 $5 万不当死亡赔偿金投资而非还学生贷款——**独立判断 + 敢于下注的勇气**
- **安全边际框架**：Apple 1999 年 $12/股，每股含 $11 现金等价物 = 花 $1 买整个苹果业务——用数字算清"错了亏多少、对了赚多少"（不对称收益的祖师爷版）
- **伟大公司可被市场忽视十年**：可口可乐 1971-1982 十年不涨、美国运通 1973-1984 十年下跌——**不代表不值得买**（时间框架：逆向投资以十年计，短线交易以天计）
- **研究痴迷才是护城河**：Burry 深夜 10 点到凌晨 2 点写投资文章——控制不了的驱动力才是竞争优势；对量化开发同样成立
- **独立风格**：Burry 学格雷厄姆和巴菲特，最终走自己的路——方法论必须适应时代环境，复制别人的 EA 不如建立自己的策略体系
- 金句：*"如果你在牌桌上 20 分钟还看不出谁是傻瓜，你就是那个傻瓜"* / *"悲观者往往正确，乐观者往往成功"*

## 三、财报与回测：都是体检报告，不是成绩单

- **财报是过去的总结**，不决定未来——真正重要的是执行（每辆车、每次升级、每个创新）；把财报当**体检**，不要当**考试成绩**
- **真正价值的信息在电话会议**：分析师问题从"公司会不会破产"转向"长期战略是什么" = 公司走向成熟的关键信号
- **拆股不创造价值**：Tesla 3-for-1、NVDA 10-for-1 后均有回调——别把数字游戏当利好
- **对 EA 开发的迁移**：**回测数据就像财报**——是过去表现总结，不是未来保证；真正重要的是策略逻辑本身和持续迭代能力（对应 SniperTrendEA 63 个版本的迭代哲学）
- 制造业标杆：Musk "We make the machine that makes the machine"——核心竞争力是制造本身；对交易者：核心竞争力是**系统化的执行机制**，不是某一次预测

## ⚡ 与 Z-Wei 体系互证

- **多时间框架共振 = 规则 3（≥2 独立信号共振）**：疯人7777 用"多周期"提供独立信号来源，Z-Wei 用"趋势线+MACD+成交量"——同一个原则的两种实现
- **Never chase a breakout = 规则 1（≥3 次确认）+ 规则 2（实体 ≥60%）**：突破后的"回测确认"就是等价格结构验证，防止追高被套
- **测量移动目标位 = 规则 5（不吃全段）**：盘整深度投射的目标 = 客观止盈位，到目标就走，不贪最后一口
- **逆向出手 = 规则 4（震荡市空仓）的镜像**：规则 4 是"无趋势不动"，逆向是"极端恐慌 + 确认信号出现才动"——两者共享同一个前提：**不预测，只对市场给出的极端状态做出规则化反应**
- **技术分析确认框架 = SniperTrendEA 过滤层的理论来源**：多周期共振、均线方向、量价确认、背离检测——EA 的 5 层过滤就是这个框架的机械实现
