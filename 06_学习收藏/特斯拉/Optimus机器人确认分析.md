# Optimus 机器人确认分析

2021年8月20日，特斯拉 [[特斯拉AI日|AI日]] 正式确认人形机器人 [[特斯拉Optimus|Optimus]] 将于2022年发布原型。本文基于直播解读，提炼三大核心模块：自动驾驶底层、Dojo超级计算机、Optimus机器人。

---

## 一、AI日三大模块

### 模块1：自动驾驶改进
- 空间人工标注 / 自动标注 / 仿真测试环境
- 通过模拟建立虚拟测评场景
- 主题核心：**FSD神经网络训练**与视觉感知系统

### 模块2：Dojo超级计算机
特斯拉发布了自研 **D1芯片**（基于7nm工艺）：
- 晶体管数量：**500亿**
- 内建 **354个训练节点**
- 内部电路长达 **17.7公里**
- 训练模组由 **25个D1芯片** 组成，算力高达 **9千万亿次**（900 PFLOPS）
- 带宽：**36TB/秒**
- 模组具独立运行能力，支持无限制联结
- 特斯拉集群模型由120个训练模组组成 → 内置3000个D1芯片 → 超过100万个训练节点 → 算力 **1.1 EFLOPs**

> **战略意义**：将来可以向其他机器学习项目提供训练服务，为股东创造"躺着赚钱"的机会。

### 模块3：Optimus 人形机器人
- 高度 **1.76米**（5'8"），重量约 **113斤**（57kg）
- 载重：最高 **45磅** 拉举 / **150磅** 硬拉
- 配置 **40个机电执行器**，支持反饋感应
- 搭载 [[FSD]] 基础芯片、自动驾驶級摄像头
- 可进行神经网络学习训练
- **安全第一前提**：速度设置保守，确保对人类无害
- 主要用途：重复性工作、危险作业、仓储物流

## 二、发布会的深层意图

1. **人才招聘是核心目的**：三个小时的活动本质上是一场全球人才招募
   - 前半段（芯片+Dojo）→ 听懂的人已经产生共鸣
   - 后半段（机器人）→ 引爆社交传播，触达尚未关注的人群
   - [[马斯克]] 的战略：利用一个活动向全球发送"超强信号"

2. **对比 Model S Plaid 发布会**
   - Model S Plaid 作为**旗舰产品发布会**，马斯克表现一般（迟到、念PPT）
   - AI日则全程投入、认真、细致、充满激情
   - 体现核心价值观：**对人才的态度 > 对产品的态度**

3. **重塑公司定位**
   - 特斯拉不光是电动车公司
   - 也是 **能源公司 + 人工智能公司 + 超级计算机公司 + 机器人制造公司**

## 三、关键洞察

- **机器人与汽车的关系**：七个月前已有预判视频——特斯拉必然会造机器人，场景涵盖战争、商业、送外卖、探矿、移民火星
- **大规模量产**是真正的挑战，特斯拉在此具备结构性优势（上海工厂经验、供应链掌控力）
- AI日对普通人的影响：看懂技术内容的人极少，但"机器人"概念成功破圈，触达全球
