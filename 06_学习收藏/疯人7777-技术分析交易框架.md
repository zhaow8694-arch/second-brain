# 技术分析交易框架

## 核心观点
- 技术分析是概率工具，不是水晶球
- 多时间框架共振 = 高概率信号
- "趋势是你的朋友"直到它不再是——尊重周线阻力

## 方法论/框架
- **测量移动**：量度盘整深度，从突破点投射目标（NVDA $700→$900→$1200+）
- **杯柄形态**：3年基底的NBIS从$50突破到$150+
- **W底/双底**：最可靠的底部反转形态（道琼斯运输指数领先指标）
- **突破+回测**：健康回调到前阻力→新支撑
- **均线系统**：8/21/200日线识别趋势
- **RSI/MACD背离**：牛背离 = 动能切换信号
- **成交量确认**：突破放量、回调缩量 = 健康


## 关键引用/数据
- "Never chase a breakout" —— 等回测确认
- 道氏理论：运输指数作为领先指标
