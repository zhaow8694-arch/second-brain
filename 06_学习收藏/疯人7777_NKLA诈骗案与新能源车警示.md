# NKLA诈骗案与新能源车警示

## 核心内容
- **Trevor Milton**（Nikola创始人）因证券欺诈被SEC起诉
- **三大欺诈类别**：
  1. **Nikola One卡车**：根本不能开——Super Bowl广告展示的是插电运行的卡车
  2. **Badger电动皮卡**：根本不存在，无原型车
  3. **氢能源基础设施和电池技术**：完全编造
- Milton声称"特斯拉在抄袭我们"——直接被视频证据打脸
- **GM合作**：通用汽车投资Nikola换取技术授权——但Nikola根本没有技术，GM于2020年12月终止合作
- 股价从$93暴跌至$15，但起诉后公司估值仍有$50亿

## 危险信号
- 工厂照片显示的是空箱子和道具，而非真实生产线
- 没有可验证的产品/原型
- CEO大话连篇但技术团队无实质成果
- 大厂合作被一一终止

## 关键数据/判断
| 指标 | 数据 |
|------|------|
| 历史高点 | $93 |
| 起诉后价格 | ~$15 |
| 起诉后市值 | ~$50亿 |

| 真实产品 | 零 |

### 警示清单
1. **不要寻找下一个特斯拉——直接买真正的特斯拉**
2. 追逐明星股票的廉价替代品是危险的
3. 类似需要警惕的公司：Faraday Future、恒大汽车、Lucid——谁会是下一个欺诈案？
4. 尽职调查铁律：不投只有PPT没有产品的公司

## 交易启示
- 新能源车赛道鱼龙混杂，基本面尽职调查比技术分析更重要
- "下一个XXX"叙事是散户亏损的经典陷阱——龙头溢价是有道理的
- 重大合作伙伴关系终止是清仓信号（GM退出NKLA时应立即离场）
- SPAC上市的公司尽调门槛低，欺诈概率更高
- 做空此类股票需要勇气，但辨识度高的造假公司有做空机会
