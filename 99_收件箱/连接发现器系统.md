# 🔗 知识连接发现器

> 让 AI 定期扫描整个知识库，发现笔记间潜在关联

## 自动触发方式

### 方式 1：会话启动时
在 `SessionStart` hook 中已集成，启动时自动调用。

### 方式 2：手动触发
需要时直接在对话中告诉我：
> "帮我扫描知识库，发现新的笔记关联"

## 扫描内容

| 扫描项 | 说明 |
|:-------|:------|
| **新笔记 → 旧笔记** | 最近7天创建的笔记与整个库的潜在关联 |
| **交易教训 → EA 版本** | 复盘经验教训与对应的 EA 版本建立链接 |
| **跨领域连接** | AI 项目 + 交易策略 + DePIN 之间的交叉点 |
| **重复主题检测** | 同一个概念在不同笔记中反复出现但未互相引用 |

## 输出格式

扫描完成后，我会在对话中输出：

```
🔗 发现 3 个潜在连接：

1. [[交易教训-危险K线识别]] ↔ [[SniperTrendEA v8.67 风控模块]]
   关联理由: 危险K线逻辑已在 v8.67 中实现为 InpMaxCandleBodyPercent 参数

2. [[AIMart 算力商品定义]] ↔ [[PulseCompute 项目构思]]
   关联理由: PulseCompute 可以复用 AIMart 的算力交易协议

3. [[Z-Wei 趋势线3次确认]] ↔ [[SniperTrendEA v8.5 过滤层设计]]
   关联理由: 趋势线3次确认 = EA 的信号过滤层#2
```

## 建议的链接

扫描后我会建议添加 `[[]]` 链接，等待你确认后再执行修改。
