# 2022年特斯拉涨价潮分析

## 背景
2022年3月，特斯拉在中美两大市场同步涨价（美国涨$1,000，中国涨¥10,000）。此时油价因俄乌冲突飙升，全美汽油均价突破$4/加仑，部分地区高达$7-8。电动车经济性优势凸显，部分地区特斯拉订单环比增长100%。

**涉及视频：**
- 2022-03-11：特斯拉又涨价，Rivian对比

## 核心分析

### 定价权来源
- 需求远大于供给，涨价是供需失衡下的理性调节而非单纯牟利
- 原材料成本上涨（摩根士丹利估算推高单车成本~$1,000）
- 特斯拉累计涨价幅度（2021年初至2022年6月）：
  - Model 3: +$10,000
  - Model Y: +$16,000
  - Model S: +$25,000
  - Model X: +$31,000
  - 总体涨幅约31%

### 宏观背景
- 俄乌冲突 → 大宗商品价格飙升 → 汽油价格创历史新高
- 高油价推动电动车需求：高油价地区订单翻倍
- 汽油车的使用成本大幅上升，电动车成为理性消费选择

## 数据/预测
- Rivian同期表现：Q4 2021亏损$24亿，计划年产不足2.5万台，股价从$190跌至$36
- Rivian手持8.3万订单但无法交付 — "Prototype is easy, production is hard"
- 特斯拉的涨价能力与传统车企形成鲜明对比
- 但作者也警示：价格弹性有边界，持续涨价最终会遭遇需求天花板

## 历史回顾价值
2022年上半年的涨价潮最终在Q4出现反转 — 10月中国首次降价、12月北美降价。这是理解特斯拉"定价权边界"的关键案例：高通胀时期特斯拉利用定价权转嫁成本，但当需求端出现疲软信号后，降价空间也同样存在。
