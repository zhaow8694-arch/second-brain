# "去马斯克化"与年底持续暴跌

## 背景
2022年11月中旬至12月初，特斯拉股价从$180持续跌至$150区间。"去马斯克化"概念首次浮出水面：股东起诉马斯克560亿薪酬方案、马斯克确定接班人、中国和北美先后降价标志需求疲软确认。同时科技行业裁员潮扩大。

**涉及视频：**
- 2022-11-18：去马斯克化+薪酬诉讼+CEO接班人
- 2022-11-22：跌无止境+裁员潮后续影响
- 2022-12-02：需求进一步恶化+北美降价+马斯克库克握手
- 2022-12-06：破纪录交付却减产20%？

## 核心分析

### "去马斯克化"概念的提出
- 股东Richard Tornetta（仅持9股！）起诉马斯克560亿美元薪酬方案不合理
- 董事会成员James Murdoch透露：**马斯克已在过去几个月内确定了下一位CEO候选人**
- 死亡威胁确实存在（5月推文为证）

### CEO继任者分析
- 下一任CEO需要三个特质：第一性原理、实干务实、了解特斯拉文化
- 否决纯技术路线候选人
- **作者看好：朱晓彤和陶琳（特斯拉中国双雄）**
  - 均2014年入职，经历7年之痒
  - 主导上海工厂建设和中国区成功

### "去马斯克化"的评估
- **短期：一定不是利好** — 马斯克是特斯拉的灵魂
- **长期：** 赛道正确+产品领先 → 类似乔布斯离开后的库克时代
  - "虽然库克一万年没搞出什么大创新，但iPhone仍把苹果做成市值第一"
  - **关键是选对赛道、做领头羊** — 特斯拉这两点已稳固

### 北美降价（需求确认疲软）
- Model 3/Y库存车立减$3,750 — 2020年以来首次降价
- Model 3库存：10月200台 → 11月475台
- Model Y库存：10月<50台 → 11月200-400台（4-6倍）
- 作者朋友贷款利率：2年前2.9% → 6.25%
- 马斯克回应："确实趋势令人担忧，美联储需要马上降息"

### 马斯克库克"握手"的深层博弈
- 苹果威胁下架推特 → 马斯克反击"公开过去所有被管控的言论"
- 库克邀请马斯克访问苹果园区 → 各退一步
- 关键观察：库克从头到尾在推特上保持沉默 — "我可什么都没说"
- **作者看的不是握手，是背后的政治角力**

### 裁员潮的连锁反应深度分析
- 科技员工薪资结构：现金+奖金+**股票（往往占大头）**
- 很多人为避税和生活不卖股票，期待财务自由
- 一旦被裁：现金断流 → 被迫卖出已暴跌的股票 → 加剧股价下跌 → 卖无可卖→ 卖房
- **"失业潮之后会迎来破产潮"**
- "你家旁边的咖啡店明年可能就吃不到了"

### 中国产销矛盾（12月6日）
- 11月中国交付100,291台（创新纪录），良品率近100%
- 全年中国交付已达65万台，远超2021全年
- 路透社/彭博社：上海计划减产20%，特斯拉辟谣"所述不属实"
- 但作者指出措辞为"所述不属实"而非"这是假的" — 玩文字游戏
- 引用9月30日特斯拉中国否认降价→10月24日即降价的先例

### Semi卡车交付
- 风阻系数0.36（布加迪凯龙0.38）
- 空载0-60英里5秒（与Model Y相当）
- 满载8万磅续航500英里
- V4超充桩，功率是V3的2倍+
- 百世100台、加拿大Vorma 130台预定

## 数据/预测
- 特斯拉股价$167（2020年11月以来首次回到此水平）
- 作者在330期提前预警头肩顶风险（$182-194区间），此后又跌15%
- 亚马逊裁员1万人
- 美国裁员人数近8万，同比暴增4倍，创近2年新高

## 历史回顾价值
"去马斯克化"概念在2022年底首次浮出水面，成为此后两年持续讨论的话题。朱晓彤在2023年初确实接管了全球生产职责（作者判断准确）。裁员潮→被迫卖股→加剧下跌的链条分析在2022年底极为精准地描述了市场机制。
