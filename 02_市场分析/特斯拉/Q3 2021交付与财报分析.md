# Q3 2021 交付与财报分析

2021年Q3，[[特斯拉]] 交付量再次打破市场预期，财报展现"教科书级别的健康度"。本文结合交付数据和财报内容，提炼核心看点、隐藏信息及未来展望。

## 二、Q3 财报核心数据（2021年10月）

### 关键财务指标
| 指标 | 数据 | 意义 |
|------|------|------|
| 汽车业务利润率 | **30.5%** | 历史级高水平 |
| 运营利润率 | **14.6%** | **历史最高** |
| 运营利润 | **$21亿** | — |
| EBITDA | **$32.1亿** | 非常扎实 |
| 碳积分收入 | **大幅减少** | 证明非依赖碳积分盈利 |

### 财报暗藏亮点
特斯拉的财务健康度全面改善：
1. **年复合利润增长率57%** — 即使大幅扩厂和研发投入
2. **偿还$15亿贷款** → 有望获得新的[[信用评级]]提升
3. **现金流极其充沛** — 偿还贷款后现金依然充足
4. 持有的比特币：买入价$3.2万 → 现价$6.6万（约$15亿账面浮盈）
5. **若出售比特币可直接覆盖全部剩余贷款**

## 三、财报没说的隐藏信息

### 1. Model S/X 利润率远高于预期
- 新款Model S/X的利润率"高到不敢说"
- Model X在Q3末刚开始交付Q4版本
- **Q4财报的利润率还将显著上升**

### 2. 德州+柏林工厂尚未计入财报
- 工厂仍在Ramp Up阶段
- 一旦计入将进一步提高整体利润

### 3. 100万辆年会仍有机会
- [[马斯克]] 亲赴Fremont工厂，要求扩大排产规模
- Fremont的潜在产能可能被低估
- **前提**：不把预期打满（避免"49.9万 vs 50万目标"的闹剧重演）

### 4. 德州保险产品
- 11月特斯拉保险将在德州推出
- 使用[[FSD Beta]]安全评分机制实时评估驾驶员
- 给驾驶员改进空间（而非直接拒保）
- 对传统保险业是颠覆式创新

## 四、股价分析

### 为什么财报好股价却不暴涨？
| 时间 | 股价 |
|------|------|
| 2-3周前 | ~$750 |
| 财报发布时 | ~$860 |
| 财报后 | 横盘$850~$860 |

**原因**：财报利好已经被**提前price in**（从$750涨到$860已提前反映预期）
- 机构在财报前6-8周已建仓完毕
- 财报日追高买期权 = 送钱给市场
- [[特斯拉]] 财报"惯杀期权"已成规律

### 历史重现展望
- 回顾2020年Q4及2021年Q1财报后的走势：**历史性大涨**
- 作者预感Q4财报后可能**历史重演**（非投资建议）
