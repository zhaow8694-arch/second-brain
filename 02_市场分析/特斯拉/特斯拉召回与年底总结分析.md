# 特斯拉召回与年底总结分析

## 一、47.5万辆召回

2021年底，特斯拉宣布召回 **47.5万台 Model 3 和 Model S**：
- **Model 3 (~35万台)**：后视摄像头线束可能因后备箱频繁开关磨损
- **Model S**：前行李箱锁扣问题
- 股价短暂跌 1-2% 后迅速拉回
- 更换线束和锁扣成本极低，影响甚微

## 二、马斯克股票卖出完毕

### 历时 2 个月的卖出计划
| 时间 | 2021年10月8日 → 12月28日 |
|------|--------------------------|
| 卖出 | 1,570万股（价值 ~$164亿） |
| 均价 | $1,043/股（最高$1,180，最低$910） |
| 行权 | 2,286万股期权（$6/股） |
| 净增 | 多持有 **700多万股** |
| 结果 | 股价 ~$1,090，几乎无影响 |

### 教训
- 当初反对马斯克卖股票的人 **一无所获**
- 马斯克交了税、降低杠杆、洗掉空头
- 投资者不要自作聪明教马斯克做事

## 三、金融危机预警再确认

12月30日马斯克回复推文：
> 现有 936 家上市公司股价超过 $1，5年后还会剩多少？
> 下一次金融危机可能在 **2022年春夏或不超过2023年**

印证了 [[马斯克金融危机预警分析]] 中的判断：
- 从供应链到美联储 Taper/加息，2022年发生概率很大
- 马斯克不但用嘴说，还用真金白银（还贷、卖股、降杠杆）做给你看

## 四、X.com 合并构想

- 投资者 Dave Lee 1年前提出概念：马斯克旗下公司应合并为 **X.com**
  - 包括：Tesla、SpaceX、Neuralink、The Boring Company
  - 目标：帮助人类进步，反映文明

### Gabby Black 反对意见
- 称这是 **"terrible idea"**
- 特斯拉 = **纯制造业 + 汽车销售**
- 把其他"B2B/B2G"业务合并进来会拖累估值
- 特斯拉股价会暴跌

### 巴菲特模式对比
- 类似伯克希尔·哈撒韦：母公司控股多个子公司
- 但 Gabby Black 认为：马斯克个人才是 Buff，不是合并公司
