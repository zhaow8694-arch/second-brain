# 滞涨周期识别与应对策略

## 核心观点
疯人7777在2022年1月就准确识别出美国经济可能进入滞涨（Stagflation），并借鉴1970年代历史经验给出了详细应对方案。滞涨的三个核心特征：高通胀 + 经济停滞 + 高失业率，货币政策陷入两难。

## 市场分析

### 滞涨的底层逻辑
- 正常衰退：需求下降 → 通胀下降 → 通缩
- 滞涨异常：供给端冲击 → 价格上涨 + 经济停摆 → 加息压通胀 = 经济更差
- 美联储困境：保就业则通胀起，压通胀则失业升（两个球一只手）

### 1970年代滞涨的教训
1. 鲍恩斯（时任美联储主席）起初认为通胀是暂时的
2. 试图将能源和食品从CPI中剔除来粉饰数据
3. 最终被迫承认通胀失控时，已经晚了
4. 沃尔克上台后才以20%利率暴力加息结束滞涨，但失业率飙至10%

### 痛苦指数（Misery Index）
- 计算公式：失业率 + 通胀率
- 历史最高：1980年6月，21.98
- 2022年测量值：约10.94（尚在警戒范围）

### 可能走势推演
1. **乐观**：供应链快速恢复，通胀自然回落
2. **中性**：加息但经济仍能承受，软着陆
3. **悲观**：加息导致经济衰退，但通胀仍高 → 滞涨长期化

## 交易启示
1. **TIPS债券（通胀保护债券）**：在滞涨环境下，TIPS是较好的固收选择
2. **房地产**：房租和房价在通胀中通常上涨，但加息可能刺破泡沫
3. **选股标准**：选择基本面强、有持续盈利能力、跨国的优质公司
4. **现金为王**：保持充足现金储备，等待恐慌后的机会
5. **灾难预演**：提前制定应对计划，而非事后被动反应
