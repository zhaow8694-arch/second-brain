# Micro-Live Observation Rules

Micro-live observation is not full live deployment.

Allowed only if:
- Robust main case0010 lineage is used.
- Aggressive set is not used.
- Account is isolated.
- Risk percent is reduced to 0.05-0.10 or minimum lot.
- Daily max-loss stop is defined.
- Forward monitor CSV files are maintained.
- Emergency stop process is understood.

Not allowed if:
- Spread/slippage blockers remain ignored.
- EA regression does not match robust baseline.
- Wrong set or wrong symbol/timeframe is loaded.
- User expects production-level reliability.
