SniperTrendEA v8.5 升级说明
版本定位
v8.5「交易哲学融合版」 在 v8.4「多因子优化版」（ADX / 时间 / 波动率 / 日线MA200）的基础上，深度融入了 Z-Wei 交易体系的核心思想，使 EA 真正向"狙击手"进化。
五大核心升级（与文章理论一一对应）
1. 危险K线过滤 InpMaxCandleATR
理论来源：《危险的K线 (The Dangerous Candle)》
问题描述：原版 EA 只看实体占比 ≥ 60%，但一根振幅达到 ATR 3 倍以上的"巨阳/巨阴"虽然实体占比也很高，本质上却是订单失衡（FVG）的耗竭点，往往是反转高点/低点。EA 在此处入场等同于"FOMO 追高"。
实现逻辑：
C++
bool IsDangerousCandle(int shift, double atr) { double range = High - Low; return (range > atr * InpMaxCandleATR); // 默认 2.5 倍 }
默认值：2.5 × ATR（建议黄金/BTC 调到 2.0-3.0）
2. 单边影线惩罚 InpMaxOppositeShadow
理论来源：《市场结构观察 #26-2-2》关于"K线干脆度"的论述
问题描述：原版 EA 的 BodyRatio 是混合判断（实体÷总长），但实际上：
•做多最忌讳上影线（卖压在最后压制）
•做空最忌讳下影线（买盘在最后承接）
只看实体占比无法分辨这两种"质量陷阱"。
实现逻辑：分离上影线 / 下影线占比，做多严控上影、做空严控下影。
默认值：0.20（反向影线不超过 K 线总长的 20%）
3. 自适应 MA200 震荡带 InpMA200BufferATR
理论来源：《分形几何思维解读市场》—— 不同市场状态需要不同的"容差"
问题描述：原版用固定点数 Buffer，对 BTC 和黄金这种波动剧烈的品种很不友好；高波动期容易被穿透形成假震荡，低波动期又过度宽松。
实现逻辑：
C++
double ma200Buffer = atr1 * InpMA200BufferATR; bool aboveMA200 = (prevClose > ma200 + ma200Buffer);
默认值：0.0（保持严格过滤，可调 0.3-0.5 用于震荡识别）
4. 点火与跟随确认 InpRequireFollowThrough
理论来源：《点火与跟随》—— 真正的趋势启动需要"共识"形成
问题描述：MACD 柱状图翻转 + 实体K线很容易在震荡区频繁出现假信号。需要一个"价格层面的最终确认"。
实现逻辑：要求突破 K 线的收盘价创出近 N 根 K 线的极值（多头创新高，空头创新低），证明确实有"跟随者"加入。
默认值：false（保守参数，开启后将进一步降低交易频次但提高质量）
5. 保留 v8.4 全部多因子框架
完整保留 ADX、时间过滤、波动率过滤、日线 MA200 趋势确认。新增过滤层与原有过滤层串联工作，全部通过才会入场。

升级后的交易哲学
"我宁愿放过 100 个机会，也不在低质量的环境中浪费一颗子弹。"
v8.5 通过 5 层质量过滤 真正贯彻了：
1.方向正确（MA200 趋势 + ADX）
2.结构成立（MACD 翻转 + 实体占比）
3.K线干脆（反向影线限制）
4.不追耗竭（危险K线过滤）
5.共识形成（跟随确认）
这正是您一再强调的："我们去适应市场，只抓我们能理解的那部分行情。"
回测建议
在策略测试器中分两组对比测试：
•Group A：仅 v8.4 多因子（关闭 v8.5 新增项）
•Group B：v8.5 全开
重点观察以下指标：
•总交易次数：B 组应显著少于 A 组（约减少 30-50%）
•胜率：B 组应高出 5-15%
•最大回撤：B 组应明显降低
•平均利润/单笔：B 组应更高
如果 B 组在牺牲交易频次后没能换来更好的盈亏比，则需要放宽 v8.5 的新参数。
