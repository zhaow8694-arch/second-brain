# 关税政策与滞胀风险

## 核心观点
- 最高法院6-3推翻IPA关税——但川普一小时内用Section 122反制
- GDP 1.4%（从4.4%腰斩）+ 核心PCE 0.4%（预期三倍）= 滞胀组合
- 关税已通过33万家企业征收$1,660亿

## 方法论/框架
- **IPA关税被推翻**：Roberts写多数意见，Gorsuch+Barrett（川普提名）投票反对川普
- **国会权力回归**：Section 122有150天有效期，需国会批准才能延续
- **滞胀机制**：
  - 关税推高PCE约0.1-0.5个百分点
  - 制造业失去约10万工作岗位
  - 贸易逆差扩大，农业破产率升10%
- **私人信贷裂痕**：OBDC-2基金停止赎回，管理$3,000亿资产
  - 私信贷行业$1.7万亿
  - 数据中心融资（AI基建）受影响

## 关键引用/数据
- "川普输了这一局，但比赛还没完"
- $1,750亿关税可能退钱——但法律流程需数月甚至数年
- "每$1关税 = $1美国消费者税"

## 个人启示
- 关税是滞胀的最大推手，直接影响所有资产的定价
- 需要跟踪Section 122的150天窗口
