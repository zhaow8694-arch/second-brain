# AGENTS.md - Grok 工作规则（GROKMACD 项目）

## 项目概述
这是一个以 MQL5 EA 策略分析和文档生成为主的工作目录。包含大量策略回测分析、结构分析、优化记录等文档，以及部分 EA 源代码。

## 核心工作规则

### 1. 自动记录规则（必须遵守）
- 所有重要分析、结论、修改建议，都必须记录到对应的文档中。
- 每次完成一个分析任务后，必须更新或新建文档记录本次工作内容。
- 重要结论和发现，优先写入文档，而不是只在对话中说明。

### 2. 文档管理规则
- 分析类内容优先使用 `.docx` 格式保存（保持和现有风格一致）。
- 重要进度和总结，可以同时维护一个 `WORK_LOG.md` 文件。
- 修改或生成 EA 代码（.mq5 / .mqh）时，必须说明修改原因和影响范围。

### 3. 工作流程
- 接到任务后，先确认任务目标和范围。
- 重要任务建议先给出计划，再执行。
- 完成后主动总结本次工作内容，并更新相关文档。

### 4. EA 版本命名规则（必须遵守）
- 迭代升级时**不得覆盖**已有 `.mq5` / `.ex5` 文件。
- 每次升级**新建**带版本号的文件，例如：`SniperTrendEA_v8.62.mq5` → `SniperTrendEA_v8.63.mq5`。
- 编译产物与源文件同名：`SniperTrendEA_v8.62.ex5`。
- 部署到 MT5 时**追加**新版本，保留 Experts 目录中的旧版本供回退。
- `#property version` 与文件名版本号保持一致。

### 5. 输出要求
- 分析结论要清晰、有依据。
- 涉及代码修改时，要说明修改前后的差异。
- 尽量保持文档结构清晰，便于后续查阅。

## 其他说明
- 本项目以文档输出和策略分析为主，代码修改为辅。
- 所有操作需注意保留原有文档结构和命名习惯。
