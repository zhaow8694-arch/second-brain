# AI 交易模型的实战边界

> 核心判断：Alpha Arena 16 天实盘对决的真相——**模型裸跑短线高频，输赢不取决于模型"聪明程度"，而取决于系统里有没有风控规则层**。DeepSeek/千问 +20% 与 GPT-5 垫底亏损的差距，恰好证明：没有规则约束的模型决策 = 高智商随机游走。这与 Z-Wei 六规则逐条互证：**AI 只配当信号发生器，规则层必须人写**。

## 一、比赛复盘：事实与数据

- **赛制**：6 大模型（DeepSeek、千问 3 Max、Claude 4.5 Sonnet、Grok 4、Gemini 2.5 Pro、GPT-5）同本金 1 万美元、同数据、同 6 币种，真实盘 16 天（10/18-11/3）
- **结果**：DeepSeek ≈ 千问 **+20%**（国产开源包揽前二），**第三至六名全部亏损**，名气最大的 GPT-5 垫底
- **透明度**：每笔交易、提示词、思维链、模型决策、持仓盈亏全部公开，链上可查——几千次单轮对话即完整实验记录
- **参考项**：Rock Alpha（扩展至股票/黄金 ETF/VIX/标普）中 DeepSeek 依旧领先、Gemini 依旧垫底——跨标的稳定，非单次运气

## 二、技术拆解：为什么"朴素"能跑

**四步循环**（每 3 分钟一次）：交易所 API 取数 → 填提示词模板 → 模型返回 JSON 决策（buy/sell/hold）→ 解析下单。

**提示词设计三要点**（赢家的共同点，且任何人可复刻）：
1. **无状态单轮**——不含历史对话，只给当前时间、各标的价格、EMA20/MACD/RSI、未平仓量、资金费率、4h 级指标（避免上下文溢出，成本恒定）→ 与 [[AI Agent与个人生产力实战|无状态模式]] 完全互证
2. **纯原始数据**——无新闻、无宏观、无"假设你是巴菲特"人设，JSON 原样输入 → 公平测基础能力，也意味着**不给模型任何交易智慧，全靠默认能力**
3. **结构化输出**——强制 JSON 决策，直接可解析下单，无自由文本歧义

**开源复现**：N of X（~6k star）、N of Zero（~2.5k）、Valuesale（~5.1k，更像投资 Agent）——赛道成熟，可白嫖改造。

## 三、实战边界：六处裸奔 vs Z-Wei 六规则（核心对照）

| Alpha Arena 缺失项 | 可见后果 | Z-Wei 规则 | 落地对策 |
|:-------------------|:---------|:-----------|:---------|
| 3 分钟高频，震荡市被迫交易 | 第三至六名亏损主因 | **规则4 震荡市空仓** | 先判定趋势状态（ADX/结构），非趋势时段禁止调仓 |
| 无趋势确认逻辑，只有指标点 | 假突破入场 | **规则1 趋势线 ≥3 次确认** | 提示词附加趋势状态量（3 次测试确认才允许入场） |
| 无 K 线实体过滤 | 上下影线误判方向 | **规则2 实体占比 ≥60%** | 附加实体/影线占比字段，未确认实体不动作 |
| 单信号即决策 | 噪音单高频进出 | **规则3 至少 2 信号共振** | 强制模型先列信号清单，逐条标注共振数，<2 不出手 |
| 无目标位/止盈约束 | 浮盈回吐、过山车 | **规则5 不吃全段** | 提示词给定 ATR 目标位，达到即止盈 |
| 无异常 K 线检测与熔断 | 极端行情硬扛 | **规则6 危险K线离场** | 附加异常巨量检测字段，触发即强制平仓+暂停 |

**结论**：模型决策 = 高智商信号生成器；**比赛没给模型装风控层 = 让学霸裸考短线**。+20% 与 -20% 之间的差距，一半是模型差异，一半是运气在边界内的投影——放大样本后，无规则层系统的期望为负（手续费 + 噪音交易）。

## 四、对自身项目的直接启示

1. **SniperTrendEA**：5 层过滤的本质就是规则层。AI 可作为"第 6 层共振确认"——但必须遵守与 v8.6 回测相同的教训：**过滤压缩利润、规则兜底保命，两者是不同目标**
2. **AIMart / compute 交易**：比赛的四步循环（数据→提示词→JSON 决策→执行）可直接复刻为 AI 决策管线；订单层永远由代码规则执行，AI 不直连下单接口
3. **工程要点复用**：无状态单轮提示词、原始数据直灌、强制 JSON 结构化输出、固定频率循环——这套架子 30 分钟可搭，价值全在提示词里塞的规则
4. **测试范式借鉴**：让模型（或你的 EA 变体）在透明竞技场互搏，是比实验室回测更残酷的验证——和 Alpha Arena 一样，**先定义失败条件，再谈收益**

## 五、边界声明（博主原话 + 补充）

- 16 天样本太小，胜者存在过拟合时间窗风险；3 分钟频率 = 短线投机 ≠ 财富管理
- 仅 6 种虚拟货币，环境过度简化；且未见止损、仓位管理、回撤熔断的披露——**比赛没有测风控，只测了选币与择时**
- 我的补充：胜者 +20%/16 天的口径若折算年化看似惊人，但 3 分钟频率下的真实体验是**高频磨损 + 尾部风险**——这正是 Z-Wei 体系拒绝高频、要求空仓的根本原因
