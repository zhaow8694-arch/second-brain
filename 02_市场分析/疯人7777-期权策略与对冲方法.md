# 期权策略与对冲方法

## 核心观点
- 三种做空方式：做空股票（风险无限）、看跌期权（风险可控）、期权价差（风险回报明确）
- 大多数人都不应该做空或使用期权——这些是高级工具
- "第一损失是最好的损失"——及时止损

## 方法论/框架
- **RIVN做空案例**：做空RIVN@$163，卖出$222看涨期权收$13K权利金
  - 做空逻辑：无核心技术、无垂直整合、IPO估值$800亿但只交付42台车
  - 仓位对冲在TSLA多仓下——降低整体风险
- **TSLA对冲策略**：在周线头肩顶时买TSLQ（反向ETF）对冲
- **NVDA覆盖式Call**：$90-100购入正股，卖$180 Call + $90 Put = 双权利金
- **Margin Call机制**：连续下跌后弱多仓被清算 → 加剧下跌

## 关键引用/数据
- "Survive first, profits come later"
- "当所有人都压一边时，市场往往向反方向走"
- 2022年9月创纪录$180亿看跌期权 + $460亿空仓
