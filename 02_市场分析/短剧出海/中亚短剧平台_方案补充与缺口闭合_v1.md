# 三、合规降级方案（Plan A / B / C）

## 3.1 触发条件

若哈国监管或律所尽调确认以下任一情况，启动降级评估：

- [ ] 短剧 App 被明确归类为「在线影院 / 大众传媒」
- [ ] AIFC IT 服务商定位不被认可，外资持股受限 ≤20%
- [ ] 数字增值税 + 内容审查双重合规成本使单元经济模型失效

## 3.2 三轨方案

### Plan A：AIFC 100% 外资 IT 平台（当前默认）

```
中国母公司（技术+内容）
    └── AIFC Private Company Ltd.（IT Platform / SaaS）
            └── 哈国公民法人代表（1%，无决策权）
```

| 优势 | 风险 |
|:-----|:-----|
| 股权清晰，利润汇出路径明确 | 传媒认定失败则整体推翻 |
| 适用英国普通法，外汇管制少 | 银行开户需董事到场（2–4 周瓶颈） |

**适用**：律所书面确认「短剧分发平台 ≠ 大众传媒」。

---

### Plan B：与本地持牌方合作

```
中国方（技术+内容+运营系统）          本地持牌方（≥80% 股权）
        │                                      │
        └──── 技术许可协议 + 内容供应协议 ──────┘
                    └── 联合品牌 App
```

| 条款要点 | 说明 |
|:---------|:-----|
| 收入分成 | 建议 70/30 或 60/40（你方/本地方） |
| 技术所有权 | 平台代码、算法、用户数据归属中国方 |
| 内容审核 | 你方 T&S 标准 + 本地方法务联签 |
| 退出条款 | 2 年后可收购本地方股权或切换主体 |

**适用**：传媒认定无法规避，但仍要做原生 App。

---

### Plan C：Telegram Mini App 先行（最低合规路径）

```
Phase C-1（0–3 月）
  Telegram Mini App + Telegram Stars 支付
  └── 验证：留存率、广告 eCPM、内容合规反馈

Phase C-2（3–6 月）
  数据达标 → 启动 Plan A 或 B 原生 App
  └── 迁移：Telegram 用户绑定手机号导入
```

| 优势 | 劣势 |
|:-----|:-----|
| 跳过应用商店审核周期 | Telegram Stars 提现链路受限 |
| 验证商业模式后再重投入 | 无法接 Kaspi 秒级提现（核心钩子弱化） |
| 合规压力低 | 用户资产沉淀在 Telegram 生态 |

**适用**：Plan A 法律路径不确定、需快速验证 PMF；**不作为长期终局**。

## 3.3 决策矩阵

| 律所结论 | 推荐方案 | 时间损失 |
|:---------|:---------|:--------:|
| IT 平台认定 ✅ | Plan A | 0 |
| 传媒认定 ⚠️ 可申诉 | Plan A + 并行申诉 8 周 | +2 月 |
| 传媒认定 ❌ 无豁免 | Plan B | +1–2 月 |
| 资金/时间极紧 | Plan C → A | C 期 3 月 |

## 4.1 用户时间争夺全景

```
                    用户每日娱乐时间（约 90–120 分钟）
                              │
        ┌─────────────────────┼─────────────────────┐
        ▼                     ▼                     ▼

        │                     │                     │
        └─────────┬───────────┴───────────┬─────────┘
                  ▼                       ▼
           【间接竞品】              【直接替代品】
           抢注意力                  Telegram 盗版切片
           不抢网赚心智              零成本、无提现
```

## 4.2 竞品分层

| 层级 | 代表 | 模式 | 对项目的威胁 | 应对 |
|:-----|:-----|:-----|:------------:|:-----|
| **L0 直接** | （暂无）中亚本土短剧 App | — | 🟢 低 | 12 个月抢窗口 |
| **L1 全球进击** | ReelShort、DramaBox（俄语上架） | IAP 付费 | 🟡 中 | 免费+网赚差异化 |
| **L2 模式验证** | FreeReels、Melolo | 免费+广告 | 🟡 中 | 证明模式可行，非区域对手 |
| **L3 间接** | TikTok、YouTube Shorts | 免费+广告 | 🟠 中高 | 竖屏短剧形态重叠 |
| **L4 替代** | Telegram 盗版频道 | 免费切片 | 🔴 **最高** | 见 4.3 |
| **L5 网赚** | 本地任务赚钱 App | 网赚 | 🟠 中 | Kaspi 提现体验对标 |

## 4.3 核心转化钩子（一句话）

> **「在 Telegram 只能看片段，在这里看全集还能提现到 Kaspi。」**

### 用户转化路径

```
Telegram 频道看到 30 秒高潮切片
        ↓
「想看结局」→ 点击 Bot Deep Link
        ↓
安装 App → 注册送 500 金币
        ↓
看 2 集免费 → 第 3 集激励视频解锁
        ↓
签到+看剧攒金币 → 满 2000 金币（$2）提现 Kaspi
        ↓
邀请好友 → 再得 500 金币（裂变）
```

### 相对 Telegram 的 3 个不可替代点

| 痛点（Telegram） | 你的解法 |
|:-----------------|:---------|
| 切片不完整、画质差 | 正版全集 + HLS 自适应 |
| 无法「赚钱」 | Kaspi 秒级提现 |
| 找剧靠运气 | 分类推荐 + 追剧进度 |

## 7.1 目标版权方清单（国内短剧）

| 优先级 | 类型 | 代表机构/方向 | 授权范围谈判要点 | 状态 |

| 🥈 | 单部爆款版权方 | 按剧谈判 | 单部 $500–2,000 | ❌ 未接洽 |
| 🥉 | AI 生成内容 | 自研 | 后期补充 | — |

## 7.2 版权合同必备条款

- [ ] **授权地域**：哈萨克斯坦、乌兹别克斯坦、吉尔吉斯斯坦（可扩展塔吉克）
- [ ] **授权语言**：俄语配音/字幕 + 哈萨克语字幕权
- [ ] **授权期限**：≥2 年，含续约优先权
- [ ] **改编权**：本土演员重拍、剧本本地化
- [ ] **分许可权**：是否可授权 Telegram 频道推广素材
- [ ] **音乐版权**：BGM 是否一并授权；未授权曲目清单

## 7.3 BGM 替换 SOP

```
Step 1: 版权交付时附「音乐清单」（曲名+出处）
        ↓
Step 2: 法务/T&S 标注三类
        ├── ✅ 已授权 → 直接使用
        ├── ⚠️ 未知 → 进入替换流程
        └── ❌ 明确侵权 → 必须替换
        ↓
Step 3: 替换方案（优先级）
        ├── 采购 royalty-free 曲库（Epidemic Sound / Artlist 企业授权）
        ├── AI 生成 BGM（Suno/Udio 商用授权待确认）
        └── 静音 + 仅保留配音（最后手段）
        ↓
Step 4: FFmpeg 混流替换音轨 → 重新入库
        ↓
Step 5: 上线前抽检 10% 集数
```

## 9.2 场景 SOP

### 场景 1：内容被举报（宗教/政治）

```
0–1h   下架涉事内容 + 全平台检索同类
1–4h   本地法务评估法律风险
4–24h  如必要：App 内公告（俄语）+ 渠道说明
       记录入 T&S 案例库，更新审核规则
```

### 场景 2：Kaspi 通道故障

```
0–30m  切换 Uzum Pay / Payme 提现（预置双通道）
30m–2h 公告：「提现延迟，预计 X 小时恢复」
2h+    联系 Kaspi 商务 + ApiPay 技术支持
       积压提现队列人工分批处理
```

### 场景 3：App Store / Google Play 下架

```
Day 0  确认下架原因（合规/技术/举报）
Day 1  准备申诉材料（内容分级、隐私政策、审核说明）
Day 1  同步上线 RuStore + AppGallery + Telegram Mini App 备用入口
Day 3  如申诉失败：Plan B 本地主体重新上架
```

### 场景 4：宗教/政治舆情发酵

```
禁止：道歉时承认平台「有错」若事实未查清
建议：「我们高度重视…已下架相关内容…欢迎举报」
渠道：Telegram 频道首发 → App 内公告 → 不主动接受当地媒体采访除非律所批准
```
