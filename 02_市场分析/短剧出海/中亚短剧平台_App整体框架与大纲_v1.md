## 一、产品定位

### 1.1 一句话定义

**中亚版「红果」：海量免费竖屏短剧，填满碎片时间；看剧攒金币，可提现到 Kaspi/Uzum。**

产品身份是**免费短剧内容平台**，不是网赚 App。

### 1.2 定位三层（主次分明）

| 层级 | 定义 |
|:-----|:-----|
| **L1 主产品** | 免费短剧内容平台 |
| **L2 使用场景** | 碎片娱乐（通勤/午休/睡前/干活间隙） |
| **L3 留存工具** | 看剧赚钱 → Kaspi/Uzum 现金提现 |

### 1.3 核心商业闭环（红果逻辑）

```
海量免费短剧 → 碎片时间观看 → 广告变现（IAA）
    → 金币激励留存 → Kaspi/Uzum 提现 → 裂变拉新 → 更多内容
```

### 1.4 核心转化钩子

| 场景 | 话术 |
|:-----|:-----|
| **拉新（Telegram）** | 「全集高清免费看，不用在频道找切片」 |
| **留存（福利）** | 「看剧顺便攒金币，能提现到 Kaspi」 |

### 1.5 目标用户（v2 · 对标红果）

| 维度 | 描述 |
|:-----|:-----|
| **核心人群** | **30–45 岁打工人大盘**，男女均衡（约 55:45）；低线级城市/县城/城郊优先 |
| **主动机** | 碎片时间看爽剧、情绪解压（占 ~70%） |
| **次动机** | 看剧签到攒金币，提现贴补通胀（留存工具，占 ~10%） |
| **典型身份** | 服务业员工、工人、司机、零售店员、主妇、年轻打工族 |
| 地区 | 哈萨克斯坦（优先）、乌兹别克斯坦（次优先） |
| 设备 | 中端 Android 为主（约 85%），4G 为主 |
| 语言 | 俄语日常使用；哈萨克语界面/协议合规必备 |
| 支付 | Kaspi / Uzum 钱包用户 |

> 完整 Persona 与 Tab 设计见：`中亚短剧平台_核心人群与Tab结构_v2.md`

### 3.2 页面结构（信息架构 · 对标红果 4 Tab）

```
底部 Tab（4 个）— 顺序固定
├── 🏠 首页 / Главная   → 推荐流 + 分类 + 榜单（默认落地页）⭐
├── 🎁 福利 / Бонусы    → 签到 + 任务 + Kaspi/Uzum 提现
├── 📺 追剧 / Мои сериалы → 在看 + 收藏 + 历史
└── 👤 我的 / Профиль   → 账号 + 看剧偏好 + 邀请 + 设置

隐藏层（非 Tab）
├── 播放页（全屏，独立路由；首页点击即播）
├── 搜索页
├── 提现确认页
└── 邀请分享页
```

> v1 的「热门 Tab」并入首页榜单区；「赚钱 Tab」更名为「福利」，避免网赚 App 观感。

### 3.3 播放页广告触发逻辑

```
进入播放
  ↓
第 1–2 集：免费连播，无广告
  ↓
第 3 集前：弹出「看 30 秒广告解锁 3 集」
  ├── 看完 → 解锁 + 奖励 30 金币
  └── 跳过 → 消耗金币 或 等待
  ↓
每 2–3 集切换：插屏广告
  ↓
剧情悬念处：激励视频弹窗「提前解锁结局」
```

## 四、后端服务框架

### 4.1 微服务 / 模块划分（初期可单体，按域拆分）

| 服务域 | 职责 | 核心接口 |
|:-------|:-----|:---------|
| **user-service** | 注册、登录、JWT、设备指纹 | `/auth/*` `/user/*` |
| **content-service** | 剧集元数据、分类、搜索 | `/drama/*` `/episode/*` |
| **play-service** | 播放地址签发、进度同步 | `/play/url` `/play/progress` |
| **ad-service** | 广告位配置、展示回调、收益统计 | `/ad/config` `/ad/reward` |
| **coin-service** | 金币发放、流水、余额 | `/coin/balance` `/coin/earn` |
| **withdraw-service** | 提现申请、审核、打款 | `/withdraw/apply` |
| **invite-service** | 邀请码、裂变关系、奖励结算 | `/invite/*` |
| **cms-service** | 运营后台 CRUD | `/admin/*` |
| **analytics-service** | DAU/留存/收入聚合 | `/stats/*` |
| **risk-service** | 反作弊评分、黑名单 | `/risk/check` |

## 七、变现系统框架

### 7.1 双引擎变现

```
┌─────────────────────────────────────────────┐
│                 变现双引擎                    │
├────────────────────┬────────────────────────┤
│   引擎 A：广告 IAA  │   引擎 B：网赚裂变      │
├────────────────────┼────────────────────────┤
│ Yandex Ads（主力）  │ 签到 + 看剧赚金币       │
│ Google AdMob（补充）│ 看广告赚金币           │
│ AppLovin（增量）    │ 邀请好友赚金币         │
│                    │ 金币 → Kaspi/Uzum 提现  │
├────────────────────┼────────────────────────┤
│ 收入：美元结算      │ 成本：金币发放（可控）   │
│ eCPM $1.5–15       │ 汇率 1000币=$1         │
└────────────────────┴────────────────────────┘
```

### 7.2 广告聚合架构

```
App 广告请求
      ↓
┌─────────────────┐
│  Mediation 层   │  In-App Bidding
│  (Yandex 主导)  │
└────────┬────────┘
         │
    ┌────┼────┐
    ▼    ▼    ▼
 Yandex AdMob AppLovin
    │    │    │
    └────┼────┘
         ▼
   最高价胜出 → 展示 → 回调 coin-service 发奖励
```

### 7.3 网赚经济参数

| 参数 | 数值 |
|:-----|:----:|
| 汇率 | 1,000 金币 = $1 |
| 注册礼 | 500 金币 |
| 每日签到 | +50 金币 |
| 看 1 集 | +20 金币（上限 10 集/天） |
| 激励视频 | +30 金币/次（上限 5 次/天） |
| 邀请好友 | +500 金币（好友看满 3 集生效） |

```
      └── KOL 合作群（50–100 个达人）
```

## 十一、技术选型
