## 一、产品定位（红果式）

### 1.1 一句话

> **中亚版「红果」：海量免费竖屏短剧，填满碎片时间；看剧攒金币，可提现到 Kaspi/Uzum。**

### 1.2 定位三层（主次分明）

| 层级 | 定义 | 用户感知 |
|:-----|:-----|:---------|
| **L1 主产品** | 免费短剧内容平台 | 「有剧看、免费、爽」 |
| **L2 使用场景** | 碎片娱乐（通勤/午休/睡前/干活间隙） | 「几分钟一集，不用动脑」 |
| **L3 留存工具** | 看剧赚钱 → 现金提现 | 「顺便赚点零花钱」 |

### 1.3 不是什么

| ❌ 不是 | ✅ 而是 |
|:--------|:--------|
| 网赚/任务赚钱 App | 短剧 App 附带福利中心 |
| 25 岁都市女性专属 | 30–45 岁打工人大盘（男女均衡） |
| 付费订阅平台 | 免费 + 广告 + 注意力变现 |
| 高端城市白领产品 | **下沉市场优先**（县城、郊区、非核心区） |

### 1.4 商业闭环（红果逻辑）

```
海量免费短剧（降门槛）
    → 碎片时间沉浸观看（注意力）
        → 广告变现（IAA 主力）
            → 金币激励留存（看剧/签到/邀请）
                → Kaspi/Uzum 提现（正向反馈）
                    → 裂变拉新 → 更多内容
```

**关键**：用户来是因为**有剧看**；留下是因为**爽 + 顺手能提现**。

## 二、核心人群定义

### 2.1 大盘画像（Primary Audience）

| 维度 | 定义 |
|:-----|:-----|
| **年龄** | **30–45 岁为核心**，延伸至 27–50 岁 |
| **性别** | **男女均衡**，女略高（约 55:45）；随剧目切换（甜宠偏女、战神偏男） |
| **地域** | 哈萨克斯坦、乌兹别克斯坦；**低线级城市 / 县城 / 城郊 > 核心区** |
| **职业** | 打工人大盘：服务业、制造业、物流司机、零售店员、家政、退休再就业 |
| **收入** | 月名义工资约 **$250–400**；对通胀敏感，但**不是**为生存而来赚钱 |
| **设备** | 中端 Android（约 85%），4G 为主 |
| **语言** | 俄语日常使用；哈萨克语界面/协议为合规必备 |
| **支付** | Kaspi（哈）/ Uzum（乌）钱包用户，已习惯移动支付 |

### 2.2 来 App 的主次动机（KANO 对标红果）

| 需求类型 | 动机 | 占比感知 |
|:---------|:-----|:--------:|
| **基本需求** | 找剧 + 看剧，碎片时间解压 | **70%** |
| **期望需求** | 推荐准、剧集多、滑动流畅 | 20% |
| **兴奋需求** | 看剧赚钱、签到提现到 Kaspi | **10%**（留存加速器） |

### 2.3 三个核心 Persona（对标红果三画像，中亚本地化）

#### Persona A：「Гульнара，36 岁，奇姆肯特」— 主妇/服务业女性

| 维度 | 描述 |

| **主动机** | 霸总甜宠、复仇逆袭，**情绪解压** |
| **次动机** | 签到+看几集，月底攒 **$3–8** 贴补家用 |
| 付费意愿 | 不为去广告付费；愿看 30 秒广告解锁 |
| 语言 | 俄语 |

#### Persona B：「Ерлан，42 岁，阿拉木图近郊」— 男性打工人

| 维度 | 描述 |
|:-----|:-----|
| 身份 | 建筑工地工人 / 货车司机 |
| 看剧场景 | 工地休息、等货间隙、睡前 |
| **主动机** | 战神归来、赘婿翻身，**爽感** |
| **次动机** | 免费海量片库，不花钱比去盗版 Telegram 强 |
| 网赚 | 会签到，偶尔提现，**不是主驱动力** |
| 语言 | 俄语 |

#### Persona C：「Диана，27 岁，塔什干」— 年轻打工人

| 维度 | 描述 |
|:-----|:-----|
| 身份 | 服装店店员 / 呼叫中心客服 |
| 看剧场景 | 通勤地铁、排班空档 |
| **主动机** | 长剧太慢，短剧 **节奏快、一集 1–2 分钟** |
| **次动机** | 邀请同事注册，偶尔赚零花钱 |

| 语言 | 俄语 |

### 2.4 次要人群（增长与破圈，非冷启动主攻）

| 人群 | 作用 | 策略 |
|:-----|:-----|:-----|

## 三、Tab 结构（对标红果）

### 3.1 红果原版对照

| 顺序 | 红果 Tab | 功能 |
|:----:|:---------|:-----|
| 1 | **首页** | 推荐短剧、找剧、多品类入口 |
| 2 | **福利** | 金币、签到、提现 |
| 3 | **追剧** | 在看/收藏/历史 |
| 4 | **我的** | 账号、设置、偏好 |

> 红果没有单独的「热门」Tab，也没有把「赚钱」放在第二位。

### 3.2 中亚版 Tab 设计（4 Tab）

```
┌──────────┬──────────┬──────────┬──────────┐
│  🏠 首页  │  🎁 福利  │  📺 追剧  │  👤 我的  │
│  Главная │ Бонусы  │ Мои сериалы │ Профиль │
└──────────┴──────────┴──────────┴──────────┘
     ↑           ↑          ↑
   核心        留存工具    复访入口
```

| 顺序 | Tab | 俄文名 | 核心职责 | 默认落地 |
|:----:|:----|:-------|:---------|:---------|
| **1** | **首页** | Главная | 推荐流、分类、搜索、**一键开看** | ✅ 冷启动默认页 |
| **2** | **福利** | Бонусы | 金币余额、签到、看剧任务、**Kaspi/Uzum 提现** | 网赚用户主动进入 |
| **3** | **追剧** | Мои сериалы | 在看、收藏、观看历史、更新提醒 | 复访追剧 |
| **4** | **我的** | Профиль | 账号、邀请码、语言、客服、看剧偏好 | 设置 |

### 3.3 为什么不用旧版 Tab

| 旧版 Tab | 问题 | v2 调整 |
|:---------|:-----|:--------|
| 🔥 热门（第二位） | 与首页推荐重复 | 合并进首页「榜单/专题」区块 |
| 💰 赚钱（第二位） | 像网赚 App，吓跑追剧用户 | 改名 **「福利」**，降视觉权重，排第二 |
| 👤 我的含历史 | 追剧路径深 | 独立 **「追剧」** Tab，对标红果 |

### 3.4 首页信息架构（Tab 1 展开）

```
首页 / Главная
├── 顶部搜索栏
├── 继续观看（上次未看完，置顶）
├── 推荐流（竖屏卡片，点击即播）⭐
├── 分类入口（霸总 / 甜宠 / 战神 / 逆袭 / 悬疑）
├── 榜单区（热门榜 / 新剧榜 / 完结榜）  ← 原「热门 Tab」内容
├── 专题运营位（节日/爆款剧）
└── 底部横幅广告（低干扰）
```

### 3.5 福利页信息架构（Tab 2 — 留存工具）

```
福利 / Бонусы
├── 金币余额 + 今日已赚（顶部卡片，不过度动画）
├── 一键提现 → Kaspi / Uzum（核心 CTA）
├── 每日签到（+50 金币）
├── 今日任务
│   ├── 看 3 集短剧 → +60 金币
│   ├── 看 1 个激励视频 → +30 金币
│   └── 邀请 1 位好友 → +500 金币
├── 金币流水
└── 规则说明（透明，建立信任）
```

**视觉原则**：福利页可以「红」，但**全 App 不能满屏金币**；首页必须以剧集封面为主。

### 3.6 追剧页信息架构（Tab 3）

```
追剧 / Мои сериалы
├── 正在追（带更新红点）
├── 我的收藏
├── 观看历史
└── 猜你喜欢（流失召回）
```

### 3.7 我的页信息架构（Tab 4）

```
我的 / Профиль
├── 头像 / 昵称 / 手机号
├── 看剧偏好设置（男频/女频/混合）→ 影响推荐
├── 邀请好友（裂变入口，不放 Tab 级）
├── 语言切换（俄语 / 哈萨克语）
├── 消息通知开关
├── 用户协议 / 隐私政策
└── 联系客服
```

### 3.8 隐藏层（非 Tab，全屏路由）

| 页面 | 进入方式 |
|:-----|:---------|
| **播放页** | 首页/追剧点击剧集；上下滑切集 |
| 搜索页 | 首页搜索栏 |
| 剧集详情页 | 长按/信息按钮（可选，红果偏直达播放） |
| 提现确认页 | 福利 Tab |
| 邀请分享页 | 我的 / 福利任务 |

## 四、核心用户路径（红果式）

### 4.1 主路径：追剧（70% 用户）

```
打开 App → 首页推荐 → 点击封面 → 全屏播放
    → 连看 2 集 → 广告解锁后续 → 加入「追剧」
        → 次日 Push「你追的剧更新了」→ 复访
```

### 4.2 次路径：福利留存（30% 触达）

```
看剧结束 → 轻提示「+20 金币已到账」→ 不强制跳福利 Tab
    → 用户自主打开福利 Tab → 签到 → 攒够 2000 币 → 提现 Kaspi
        → 到账推送 → 次日再来
```

### 4.3 拉新路径：Telegram → App

```
TG 频道看 30 秒切片 → 「看全集」按钮
    → 安装 App → 首页直接播该剧（跳过注册摩擦）
        → 注册送 500 金币（播完 3 集后轻弹）
```

## 六、产品参数（随人群 v2 微调）

| 参数 | v2 建议 | 依据 |
|:-----|:--------|:-----|
| 默认落地 Tab | **首页** | 追剧为主 |
| 新用户注册时机 | 连看 **3 集后**再弹 | 降低首访摩擦（红果式） |
| 注册礼 | 500 金币 | 保留，但不挡播放 |
| 最低提现 | 2,000 金币（≈$2） | 对标「一杯茶/咖啡」 |
| 首页金币动画 | **关闭** | 避免网赚 App 观感 |
| 看剧结束提示 | 底部轻条「+20 金币」 | 告知但不打断 |
| SVOD 去广告 | **暂不上线** | 下沉用户不愿付费 |
| 看剧偏好 | 我的页可设男频/女频 | 对标红果偏好 |

## 七、数据验证指标（上线后校正画像）

| 指标 | 健康值 | 说明 |
|:-----|:------:|:-----|
| 首页 → 播放转化率 | > 40% | 内容平台核心指标 |
| 人均日观看集数 | > 15 集 | 碎片娱乐深度 |
| 福利 Tab 日活占比 | 20–35% | 太高=网赚工具化，太低=留存工具失效 |
| 男女用户比 | 45:55 – 55:45 | 均衡区间 |
| 年龄 30–45 岁占比 | > 50% | 验证打工人大盘 |
| 次留 / 7 留 | > 35% / > 20% | 追剧留存，非提现留存 |
