# 小盘股周期与板块轮动规律

## 核心观点
疯人7777在2023年6-7月持续强调"小盘股的夏天"，准确预判了IWM、ARKK以及中小盘科技股的上涨。核心逻辑：大盘科技股领涨后的资金溢出效应 + 降息预期 = 小盘股表现期。

## 市场分析

### 小盘股夏天的时间线（2023年）
| 时间 | 标志事件 |
|------|----------|
| 6月26日 | IWM形成旗形突破，首次提示小盘股夏天 |
| 7月7日 | IWM回调但未破位，建议逢低买入 |
| 7月12日 | CPI数据发布前IWM强势突破，连续两天Follow Through |
| 7月13日 | CPI超预期回落，IWM跳空高开，小盘股全面爆发 |

### 轮动特征
1. **资金从大盘科技流向小盘**：领涨股（苹果、微软）开始休整时，小盘股开始表现
2. **领先指标**：ARKK（木头姐）是典型的小盘成长风向标
3. **回调特征**：小盘股突破后往往有回调确认，这个回调是加仓机会而非离场信号
4. **板块间轮动顺序**：BTC/加密 → 大盘科技 → 半导体 → 小盘股/金融/能源

### 选股逻辑
- **科技中概股**：阿里巴巴（周线头肩底）、NIO（杯柄突破）
- **小盘科技**：UPST（旗形突破）、SOFI（WD形态）、CRM（三角旗形突破）
- **降息受益**：房地产、金融、消费
- **贵金属**：黄金/白银突破下降趋势线，确认上涨趋势

### 市场广度验证
- 观察列表"多红少绿" → 市场整体强势
- 每天1-2只观察股涨幅>10% → 市场赚钱效应强
- 领涨股修整 + 跟涨股补涨 → 健康轮动

## 交易启示
1. **IWM突破200日均线是小盘股启动的关键信号**
2. **小盘股夏天最好用"买入持有"而非短线交易**：过早卖出会错失主升浪
3. **关注降息预期升温时的小盘股表现**：降息预期 = 小盘股催化剂
4. **回调加仓策略**：突破后的第一次回调是最佳的二次买入点
5. **并非所有小盘股都能涨**：需要有基本面支撑或技术面突破信号
