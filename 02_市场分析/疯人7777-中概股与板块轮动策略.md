# 中概股与板块轮动策略

## 核心观点
- 板块轮动顺序：大科技(M7) → 中概股 → 中小盘 → 加密
- 当大科技盘整时，资金流向尚未启动的板块
- 2024年9月中国刺激政策引发中概股暴涨盛宴

## 方法论/框架
- **领先指标**：IWM（小盘股）+ DJT（运输指数）+ RSP（等权重标普）表现强势 = 市场健康
- **NIO技术分析**：杯柄突破，$7→$9.5+
- **BABA技术分析**：头肩底突破 + MACD底背离，类似TSLA 2020底部形态
- **SE**：下降三角形突破 + RSI/MACD牛背离
- **MARA/CLSK**：BTC矿股作为加密代理，$15→$18（+25%），$9→$15（+45%）
- **HOOD**：最佳加密交易平台，$120入场+12%

## 关键引用/数据
- KWEB（中概ETF）2024年9月单日涨28%
- "小盘股的夏天要来了"
- "入场时机和方向同样重要"——对的股票但错的时机=亏损
