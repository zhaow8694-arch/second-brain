# 📁 模板目录

> 用于 Templater 插件的笔记模板

## 可用模板

| 模板 | 用途 | 快捷键建议 |
|:-----|:-----|:----------|
| `决策日志模板.md` | 交易决策记录 | Ctrl+Shift+D |
| `每日笔记模板.md` | 日记自动生成 | 每日自动 |

## 使用方法

需要安装 **Templater** 社区插件：
1. 设置 → 社区插件 → 浏览 → 搜索 Templater
2. 启用后，在 Templater 设置中指定模板文件夹为 `.templates/`
3. 通过快捷键或命令面板插入模板
