# 加密板块轮动规律——从BTC到矿股到ETH

## 核心观点
疯人7777在2025年9月-10月期间多次提及加密板块内部的资金轮动顺序：BTC → BTC相关股票(MSTR等) → BTC矿股(MARA/CLSK) → ETH/山寨币。识别并利用这种轮动可以最大化收益。

## 市场分析

### 标准轮动顺序
```
【第一阶段】BTC突破关键阻力 → 资金流入BTC现货/ETF
【第二阶段】MSTR等BTC treasury play启动（比值突破）
【第三阶段】BTC矿股启动（MARA、CLSK、IREN）
【第四阶段】资金扩散到ETH和山寨币
【第五阶段】黄金等贵金属同步上涨（流动性全面泛滥）
```

### 具体案例（2025年9月-10月）
| 时间 | 阶段 | 表现 |
|------|------|------|
| 9月初 | BTC回调筑底 | 矿股提前见底（MARA 15美元） |
| 9月中 | FOMC前后 | BTC反弹，矿股走强 |
| 9月下旬 | BTC突破新高 | MSTR带动BTC相关股票上涨 |
| 10月初 | 矿股全面爆发 | MARA从16→20，CLSK从9.6→17 |
| 10月中 | BTC清算后 | 矿股相对强度更强（资金在流入） |

### ETH作为后周期品种
- ETH在2025年5月初入场，6月初减仓，回踩220日均线时重新建仓
- 涨到3400美元+
- SBET（ETH杠杆产品）从约7000美元涨至23倍（6万美元+）
- ETH通常滞后于BTC 2-4周启动

### 轮动验证指标
- **BTC.D（BTC dominance）**：BTC dominance上升时资金集中在BTC，下降时资金在向山寨币扩散
- **MSTR/BTC比值**：比值上升表示资金在通过MSTR加杠杆BTC
- **MARA/BTC比值**：矿股比值启动通常是轮动进入第三阶段的信号

## 交易启示
1. **不要在所有阶段持有同一类资产**：BTC突破期持有BTC现货，矿股启动期轮动到矿股
2. **矿股启动往往在BTC盘整期**：当BTC在高位盘整而矿股开始补涨，说明轮动进行中
3. **ETH的滞后性意味着补涨空间**：如果BTC已大幅上涨而ETH还没动，可能是ETH做多的时机
4. **关注BTC.D的趋势变化**：是判断轮动阶段的核心指标
5. **在轮动末期（山寨币暴涨）应开始减仓**：往往预示着趋势末端
