# 比特币矿股周期与交易策略

## 核心观点
疯人7777在2025年9月至10月期间精准捕捉了比特币矿股（MARA、CLSK、IREN等）的大级别突破行情，提出"BTC先行、矿股跟随"的板块轮动逻辑。

## 市场分析

### 矿股启动时间线（2025年）
| 日期 | 事件 |
|------|------|
| 9月2日 | 公开强调"不再看空矿股"，MARA 16美元、CLSK 9.6美元 |
| 9月16日 | FOMC前矿股开始走强 |
| 9月29日 | MARA 16美元突破，当日涨15.5% |
| 10月7日 | BTC创新高，MARA涨9.3%、CLSK涨至17美元（3倍） |
| 10月15日 | BTC单日清算192亿美元后V转，矿股更强：MARA突破19美元 |

### 关键观察
1. **板块轮动顺序**：BTC突破 → BTC ETF资金流入 → 矿股补涨（滞后约1-2周）
2. **强弱分化**：CLSK最强（9月初9.6美元→10月中22美元），IREN次之，MARA跟涨
3. **回调中的相对强度**：10月15日BTC跌17%，但矿股价格仍高于9月高点，说明资金在流向矿股

### 选股逻辑
- **CLSK/IREN**：有AI/HPC业务转型概念，估值弹性更大
- **MARA**：纯矿股，跟随BTC更紧密，适合BTC趋势明确的阶段
- **BFARM**：约线级别突破，月线首次站上长期阻力，牛转信号

## 交易启示
1. **跟随BTC趋势做矿股**：矿股的Beta通常为2-3倍，适合在BTC趋势明确时使用
2. **BTC大幅回调后关注矿股相对强度**：如果矿股价格高于上一轮BTC同价位，说明资金在净流入
3. **分批建仓**：不要一次性满仓矿股，采用"启动信号→小仓位→确认加仓"的策略
4. **止盈纪律**：矿股波动极大（单日30%+），需要有明确的止盈计划
5. **板块轮动末期警惕**：当矿股开始"狂飙"时，往往是趋势末段，需要开始减仓
